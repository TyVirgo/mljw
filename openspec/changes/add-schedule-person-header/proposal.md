## 为何

学生「我的课表」抽屉表头仅有固定标题，无法一眼确认是谁的课表；管理端亦需能展示老师侧课表身份（Staff ID + 姓名）。长姓名需省略显示。

## 变更说明

- 学生课表抽屉（在线选课 / 我的课程 / 加退课）：表头展示「学号 + 姓名」，过长省略（完整可用悬停）
- 管理端可展示老师侧：讲师详情「本学期课表」区块表头展示「Staff ID + 姓名」+ 周课表演示，同样省略
- 管理端监控详情：抽屉表头带学生学号 + 姓名
- 共用 `formatSchedulePersonLine`；原课表说明文案保留为副提示

## 非目标

- 不新建完整教师排课业务系统
- 不改周课表格子算法
