## 新增需求

### 需求：学生课表表头身份

学生端「我的课表」抽屉 MUST 在表头展示当前学生的学号与姓名；姓名过长时 MUST 省略显示且可通过悬停查看全文。

#### 场景：打开我的课表

- **当** 学生打开我的课表抽屉
- **则** 表头可见学号与姓名（长名带省略）

### 需求：管理端可展示老师侧课表身份

管理端展示老师课表时，表头 MUST 展示 Staff ID 与姓名；长名同样省略。入口为讲师信息详情中的「本学期课表」区块（演示排课即可）。

#### 场景：查看讲师课表区

- **当** 管理员在讲师详情中查看课表区块
- **则** 表头可见 Staff ID 与姓名，并可见周课表演示格

### 需求：管理端查看学生课表身份

管理端选课监控详情抽屉 MUST 在表头展示该学生的学号与姓名（与学生端同一格式约定）。

#### 场景：打开监控详情

- **当** 管理员打开选课监控详情
- **则** 抽屉表头可见学号与姓名
