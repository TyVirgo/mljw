# 选课管理-缴费名单 规格（合并）

## 说明

以下为各历史 delta spec 原文按来源拼接并做术语中文化处理。整理正式需求文档时，应按场景重写为「用户故事 / 验收标准」，消除重复与过时条目。

## 来源 `add-fee-roster-maintenance` / 能力 `course-registration`

## ADDED Requirements

### Requirement: 缴费名单双 Tab
系统 必须提供「未缴费」「已缴费」两个 Tab。完成选课 必须NOT 与本页缴费状态联动。

### Requirement: 未缴费主表与搜索
未缴费主表 必须按学生聚合展示。搜索 必须支持学号、姓名、专业、入学批次、选课学年学期、是否欠学费。是否欠学费表头 必须提供 tooltip「来自学籍模块，学生是否欠学费」，单元格 必须以胶囊样式展示 Y/N。选课学年学期 必须可区分数据所属选课学期。选课数量 必须等于该生有效课程副表行数，并 必须展示于选课学年学期与已选学分之间。已选学分 必须等于该生课程副表全部课程学分之和。

#### Scenario: 超学分与人工补录均可见
- **WHEN** 学生已选学分超过最低学分，或由老师新增/导入写入未缴费名单
- **THEN** 该生 必须出现在未缴费主表

### Requirement: 未缴费工具条
未缴费工具条 必须在左侧提供「新增」「同步」「导出」，统计文案 必须与按钮同一行并右对齐。

#### Scenario: 同步超学分学生
- **WHEN** 老师点击「同步」
- **THEN** 系统 必须先弹出确认；确认后 必须将已选学分超过最低学分且尚未在未缴费/已缴费名单中的学生一次性写入未缴费，并 必须以页面提示反馈成功摘要（新增/跳过数量）或失败

#### Scenario: 新增未缴费学生
- **WHEN** 老师新增一名不在未缴费、且不在已缴费名单的学生并确认
- **THEN** 该生进入未缴费名单；写入时 必须静默使用默认选课学年学期（活跃批次或选项首项），弹窗 必须NOT 展示学年学期选择；搜索 必须为 3 列 × 2 行并含入学批次

### Requirement: 未缴费课程副表
抽屉副表 必须展示该生全部已选课程（占位空课可不展示），列 必须包含课程代码、名称、学分、课程类型、课程分组、课程来源。

### Requirement: 已缴费导入回写
系统 必须允许在已缴费 Tab 导入已缴费学号名单。导入 必须将命中的未缴费学生移入已缴费 Tab。已缴费列表 必须至少展示基础学生信息（学号、姓名、专业、入学批次、选课学年学期）。已缴费 Tab 必须NOT 要求完整课程副表。必须NOT 对接在线支付。

### Requirement: 未缴费双 Sheet 导出
未缴费导出 Excel 必须含 Sheet1 学生名单（含选课学年学期、选课数量、是否欠学费）与 Sheet2 课程明细（含课程来源）。

## 来源 `align-fee-source-drop-attachment` / 能力 `course-registration`

## ADDED Requirements

### Requirement: 缴费名单课程来源与学生端一致
缴费名单副表与导出中的课程来源 必须与学生选课结果一致，展示第一轮/第二轮/第三轮选课或管理员添加。

### Requirement: 退课选填附件
退课申请表单 必须在申请说明之前提供选填附件上传。必须NOT 因超期通道要求强制附件。

### Requirement: 申请窗口外禁止发起
当不在加退课申请时间范围内时，系统 必须提示不在申请时间范围内，且 必须NOT 允许发起或提交申请。

## 来源 `polish-fee-roster-import-paid-tab` / 能力 `course-registration`

## ADDED Requirements

### Requirement: 缴费名单导入在已缴费 Tab
系统 必须仅在已缴费 Tab 提供导入；未缴费 Tab 必须保留导出且 必须NOT 展示导入。

### Requirement: 已缴费导入模板列
下载模板 必须包含学号、学生姓名、入学批次、课程缴费状态列，并 必须标明内容为示例、需替换为实际数据。导入匹配 必须以学号为准。

### Requirement: 缴费名单管理命名
管理端菜单文案 必须为「缴费名单管理」。

### Requirement: 导入名单日期列
已缴费名单表格 必须将导入回写日期列展示为「导入名单日期」（不得使用「回写日期」文案）。

## ADDED Requirements（增量 2026-07 统一主表）

### Requirement: 需要缴费学分与是否缴费
学生主表 必须在「最高学分」列之后展示「需要缴费学分」，其值 必须为已选学分减去最低学分（结果小于 0 时展示 0）。主表 必须展示「是否缴费」列，取值为是或否。

#### Scenario: 计算需要缴费学分
- **WHEN** 某生已选学分 14、最低学分 12
- **THEN** 需要缴费学分 必须为 2

### Requirement: 双 Tab 共用主表
未缴费与已缴费 Tab 必须共用同一套主表字段（含选课数量、学分区间、需要缴费学分、是否欠学费、是否缴费、查看课程）；已缴费 Tab 必须额外展示「导入名单日期」。Tab 必须按是否缴费筛选并分页。

#### Scenario: 已缴费可看课程
- **WHEN** 学生已导入为已缴费
- **THEN** 该生课程明细 必须仍可查看，且 必须NOT 因导入而丢失

### Requirement: 导入匹配学号姓名并改标志
已缴费导入 必须按学号与姓名同时匹配未缴费学生；命中后 必须将是否缴费改为是、写入导入名单日期，且 必须保留原课程明细。导入模板列 必须与未缴费导出学生名单字段一致，且 必须NOT 包含导入名单日期（该时间于导入时生成）。

#### Scenario: 姓名不一致则不移入
- **WHEN** 导入行学号命中但姓名与未缴费名单不一致
- **THEN** 系统 必须NOT 将该生标为已缴费

## ADDED Requirements（增量 2026-07 Demo 与胶囊）

### Requirement: 是否缴费颜色胶囊
「是否缴费」单元格 必须与「是否欠学费」使用相同风格的红/绿颜色胶囊区分（是为绿、否为红）。

### Requirement: 缴费名单 demo 覆盖面
原型 demo 必须包含多名未缴费与已缴费学生，覆盖不同专业、选课学年学期与欠学费状态，便于演示双 Tab 与筛选。
