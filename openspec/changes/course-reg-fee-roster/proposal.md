# 选课管理-缴费名单

> 本变更包由同菜单下多个历史 OpenSpec 变更合并而成，供后续整理需求文档使用。实现状态以原型代码为准；本包作为需求沉淀，不重复驱动增量开发。

## 背景与动机

缴费名单供教务将「已选学分超过最低学分」的学生及已选课程清单导出给线下财务，财务收费后通过导入回写已缴费状态。系统不对接在线支付，也不联动「完成选课」。本包按维护与回写链路重组，便于写需求文档。

## 能力范围（按逻辑分组）

### 1. 缴费名单维护主流程

- 页面分 Tab：**未缴费** / **已缴费**。
- 自动展示超学分学生；老师可「同步」一键纳入超学分学生，也可「新增」例外补录。
- 副表展示该生已选课程明细清单，支持导出给财务。

### 2. 课程来源与学生端对齐

- 缴费名单「课程来源」与学生端选课结果一致：第一/二/三轮选课、管理员添加（含导出字段）。
- 退课表单恢复选填附件；申请窗口外明确提示并禁止发起。

### 3. 已缴费导入与文案

- 「导入已缴费」回写入口放在 **已缴费** Tab（避免在未缴费 Tab 误操作）。
- 菜单「维护」改为「管理」；已缴费列表「回写日期」文案避免误解为系统回写时间；导入模板列补齐必要字段。

### 4. 多行搜索区布局（增量）

- 查询 / 重置与**第一行**筛选项水平对齐，不得因字段换行垂直居中悬空。
- 溢出条件（如「是否欠学费」）放入可折叠第二行；提供展开/收起，**默认展开**。
- 与学籍列表搜索（`MovementListSearchBar`）及 `list-page-search.css` 范式一致。

### 5. 新增未缴费弹窗与同步（增量）

- 「新增未缴费学生」去掉「选课学年学期」选择；写入时静默使用默认学年学期（选项首项/活跃批次）。
- 弹窗搜索改为 **3 列 × 2 行**：学号、姓名、学院、入学批次；过滤支持入学批次。
- 「同步」点击先确认，再提示成功（含新增/跳过摘要）或失败。

### 6. 统一主表与缴费标志（增量 2026-07）

- 未缴费 / 已缴费 **共用同一套学生主表列**，按「是否缴费」是/否分页展示（Tab 为快捷筛选）。
- 最高学分后增加「需要缴费学分」= 已选学分 − 最低学分（小于 0 时按 0）。
- 增加「是否缴费」列（是/否）；导入时按 **学号 + 姓名** 匹配未缴费行，将标志改为「是」并写入「导入名单日期」，**保留课程明细**，已缴费可「查看课程」。
- 已缴费较未缴费仅多「导入名单日期」；导入模板列与未缴费导出学生字段一致（不含导入时间，时间导入时生成）。

### 7. Demo 充实与是否缴费胶囊（增量 2026-07）

- 充实未缴费 / 已缴费 demo（多专业、多学年学期、欠学费 Y/N 交叉、不同导入日期），便于演示搜索与双 Tab。
- 「是否缴费」单元格与「是否欠学费」同用红/绿颜色胶囊（是/Y 绿，否/N 红）。
