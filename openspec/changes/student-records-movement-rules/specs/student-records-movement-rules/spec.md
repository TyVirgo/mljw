# 学籍管理-异动规则设置 规格（合并）

## 说明

以下为各历史 delta spec 原文按来源拼接并做术语中文化处理。整理正式需求文档时，应按场景重写为「用户故事 / 验收标准」，消除重复与过时条目。

## 来源 `add-movement-rule-condition-columns` / 能力 `movement-rule-settings`

## 新增需求

### 需求：异动规则设置页增加条件展示字段

系统应在异动规则设置列表中展示每条规则适用的学期类型、学生类别、异动类别及申请时间范围，帮助业务人员快速识别规则用途。

#### 场景：新增列展示
- **当** 用户查看异动规则设置列表
- **则** 表格在「规则名称」与「规则值」之间显示 4 列：学期类型、学生类别、异动类别、申请时间（开学后【周】）

#### 场景：字段只读
- **当** 用户查看新增列
- **则** 列中文本仅用于展示，不响应编辑操作

#### 场景：不适用字段展示占位符
- **当** 某条规则对某个条件字段不适用时
- **则** 该列显示 `-`

#### 场景：申请时间范围展示
- **当** 规则的 `applicationWeek` 存在时
- **则** 显示为 `start ~ end` 格式
- **否则** 显示 `-`

#### 场景：向后兼容
- **当** 已有 `movement-rules-v2` 存储数据缺少 `condition` 字段时
- **则** 系统使用内置默认值补齐，不破坏现有数据

## 来源 `add-movement-rule-settings` / 能力 `movement-rule-settings`

## 新增需求

### 需求：异动规则设置页

系统应提供异动规则设置菜单页，展示内置规则列表；不允许新增、删除或搜索。

#### 场景：菜单导航
- **当** 用户在学籍异动侧边栏选择「异动规则设置」
- **则** 系统展示内置规则表格

#### 场景：规则名称只读
- **当** 用户查看规则列表
- **则** 规则名称显示内置文案且不可编辑

#### 场景：修改规则值
- **当** 用户点击某行「修改」并保存新规则值
- **则** 系统更新该规则数值并持久化到 mock 存储

#### 场景：切换是否启用
- **当** 用户切换某行是否启用开关
- **则** 系统立即更新启用状态并持久化

#### 场景：无新增与搜索
- **当** 用户查看异动规则设置页
- **则** 不显示新增按钮与搜索区域

## 来源 `refine-chinese-programme-transfer-rules` / 能力 `movement-rule-settings`

## 修改需求

### 需求：异动规则设置页

#### 场景：中国学生长学期转专业规则
- **当** 用户查看 MR004
- **则** 学期类型为长学期，学生类别为中国，申请时间为 5~7 周，规则值 0/1 表示是否允许申请

#### 场景：中国学生短学期转专业规则
- **当** 用户查看 MR005
- **则** 学期类型为短学期，学生类别为中国，申请时间为 `-`，规则值默认 0 表示不允许申请

#### 场景：MR004/MR005 规则值校验
- **当** 用户编辑 MR004 或 MR005 的规则值
- **则** 仅允许输入 0 或 1

## 来源 `refine-movement-rule-settings-split-rows` / 能力 `movement-rule-settings`

## 修改需求

### 需求：异动规则设置页

#### 场景：Local 长短学期分行
- **当** 用户查看异动规则设置列表
- **则** Local 学生转专业时限分为长学期与短学期两行，各自可配置 Week 规则值

#### 场景：规则名称动态展示规则值
- **当** 用户查看或修改某条规则的规则值
- **则** 规则名称中以 `{value}` 展示当前规则值，不写死数字

## 来源 `refine-mr004-editable-application-week` / 能力 `movement-rule-settings`

## 修改需求

### 需求：MR004 申请时间编辑

#### 场景：编辑申请时间窗口
- **当** 用户点击 MR004 的「编辑」
- **则** 申请时间列的起止周变为可编辑输入框，中间 `~` 不变

#### 场景：保存校验
- **当** 用户保存且起始周 < 1 或截止周 < 起始周
- **则** 显示校验错误，不保存
