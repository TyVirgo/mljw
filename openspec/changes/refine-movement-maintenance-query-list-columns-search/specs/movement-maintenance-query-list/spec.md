## 修改需求

### 需求：异动维护/查询主表列顺序统一

异动维护与异动查询主表前缀列顺序应统一为：序号、Status、审批环节、是否实施、Student ID、Name、Intake、Programme、生效日期，其余列接后。

#### 场景：生效日期表头文案
- **当** 用户查看维护或查询主表
- **则** 生效日期列表头显示为「生效日期」（非「生效学期」）

### 需求：搜索区字段调整

搜索区应包含 9 项条件，并移除「申请学年学期」「专业代码」；新增 nationality 搜索与列；studentType 作为国籍类别展示。

#### 场景：搜索区布局
- **当** 用户打开维护或查询页
- **则** 搜索区对齐学生基本信息样式：主行常用条件 + 查询/重置（带图标）+ 更多/收起

#### 场景：点击查询才应用筛选
- **当** 用户修改搜索条件
- **则** 仅点击「查询」后列表才按条件过滤

### 需求：导出列顺序与主表一致

维护/查询导出字段默认顺序应与当前主表列顺序一致。
