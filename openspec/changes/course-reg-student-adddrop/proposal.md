# 选课管理-学生加退课

> 本变更包由同菜单下多个历史 OpenSpec 变更合并而成，供后续整理需求文档使用。实现状态以原型代码为准；本包作为需求沉淀，不重复驱动增量开发。

## 背景与动机

加退课/重修申请独立于三轮主选，供学生在 Add/Drop 窗口内发起 Add、Drop 或 Retake。历史迭代补齐列表页骨架、申请表单字段、课程选择器与文案/布局统一。本包按申请发起链路重组，便于写需求文档。

## 能力范围（按逻辑分组）

### 1. 加退课申请列表页

- 增加标准搜索区（类型、状态、关键词）+ 查询/重置；「发起申请」移至搜索区下方 toolbar。
- 申请记录 demo 补齐各类型/状态/通道组合与分页；布局对齐批次/审批等列表页（提示 callout → 搜索 → 操作 → 表）。
- **列表列（增量）**：去掉「退课通道」列；「申请课程」拆为「添加课程名称 / 退课课程名称 / 重修课程名称」三列，格式统一为「课程编码 + 课程名称」；增加「详情」操作与只读抽屉（展全申请填写内容，对齐学籍异动详情方式；无审批流）。
- **菜单与取消（增量）**：学生菜单「选课历史」与「加退课/重修申请」互换位置；操作增加「取消」（审批开始前可见，确认后归档为已取消，tip 对齐学籍）；详情分区灰条 + 标签上置值下、附件卡片（预览/导出），管理端详情同步排版（仍突出审批流）。

### 2. 申请表单字段与课程选择

- 申请弹窗字段顺序：学年学期 → 申请类型 → 课程 → 申请说明 →（Drop）退费抵免是/否 →（超期 Drop）附件。
- 「操作类型」改称「申请类型」；Drop 需退费抵免标识；超期退课仍须附件；补充通用申请说明。
- 课程字段改为只读展示 +「选择」打开课程选择器（复用课程库表格选择模式，单选、适配加退课候选池）。

### 3. 表单布局与文案统一

- 弹窗两列布局；申请说明/Drop tip/退费抵免/附件整行；退费抵免用更直观控件；必填星号突出；灰色 rule tip 与浅蓝说明条一致。
- `addDropWindow`、`roundColAddDrop` 文案统一为「加退课/重修申请」（英：Add/Drop/Retake）；学年学期与范围批次选项倒序（较新在前）。
- 「演示教学周」与左侧通道说明共用 tip 底色/边框（随 info/warning 变色），便于后续接真实教学周后移除。

### 4. 加课选课学分细化 + 申请不进选课排队（增量）

- 加课/加退关联选课弹窗「本学期学分」采用方案 B：GE 总分 + GE 文/商/理，以及 ME 总分 + ME 文/商/理。
- 加退课/重修申请（含加课、重修、加退关联）**不进入**在线选课排队；仅正常在线选课走排队队列。
- 有余量课程提交加课/重修后立即锁定 1 个名额，申请进入管理端审批流转；拒绝或学生取消时释放名额。
- 审批通过后需缴费时，缴费宽限天数取选课规则 CR107（默认 2 天）；逾期未缴则课程不算选上（规则语义，原型写入截止日字段）。

### 5. 加课候选文商理 + 审批列表展示（增量）

- **专业选修（ME）默认校选类别为文科**；当前演示生默认为文科，加课/在线选课 **只能看到文科 ME**。公共选修（GE）不按学生科类过滤，加课候选须同时有文、商、理三类课。
- 加课选择器名额状态「冲突」改为「时间冲突」；演示仅保留 COMP201 分组 03 为时间冲突，其余候选分组有余量且不与已选课表冲突。
- 管理端加退课审批：待审批有勾选，已提交/历史无勾选；无勾选时冻结列 `left` 按「序号 → 申请单号」重算，避免申请单号盖住状态列。三 Tab 去掉学分列（`x/20`）。
- 「上课时间地点」按时段分行，**同一时段整行不换行**（审批三 Tab + 学生加退列表 + 加课选择器）。
- **超出学分、预估费用、账单同源**：超出学分 > 0 才有费用与缴费状态；=0 则费用为 0、账单为「—」。

### 6. 选择器状态冻结 + 审批详情（增量）

- 加课选择器「状态」列冻结；分页默认 20 行。
- 审批详情去掉「专业/入学批次 · 学分 x/y」条与整块「校验结果」。
- 学年学期、联系电话必须有值（取申请填写内容 / demo 补种）。
- 详情加课、退课、重修课程：左「课程名称」、右「课程编码」（列表列仍为编码+名称）。
- 去掉课程分区内重复的「预估费用」，只留「费用预估」合计；加退课相关金额统一带 **RMB**。
- 详情学生声明复用申请时整块（浅黄底、说明文案、只读勾选框）。

### 7. 重修节先选本学期课（增量 2026-08）

- 重修节去掉「从往期成绩单选择」「曾修课程（课号与课名）」。
- 先选本学期重修课程；第二行带回曾修成绩；曾修学年学期默认申请学年学期的上一学期（02/04/09）。
- 第三行左重修类型、右课程分组；其后带回起止周、上课时间地点、教师、学分与费用。

### 8. 屏蔽加退关联（增量 2026-08）

- 学生端类型 Tab 与管理端审批（列表、计数、类型筛选、导出）先不展示加退关联，只保留加课、退课、重修。
- 关联 demo 与内部表单逻辑可保留，页面不可发起、不可审批看见。

### 9. 重修节对齐问卷 SECTION IV（增量 2026-08）

- 曾修课名用本学期重修课程代替，不再单独展示曾修课号课名。
- 曾修成绩、曾修学年学期改为必填下拉（有枚举源；学期默认上一学期，选课后可改）。
- 上课时间地点、任课教师：选分组可带回；无数据时手填，带问卷示例提示；均为必填。
