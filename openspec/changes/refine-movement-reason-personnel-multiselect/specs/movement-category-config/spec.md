## 修改需求

### 需求：异动原因适用人员类别多选

异动类别「设置原因」中每条原因应提供适用人员类别多选（老师、学生），默认双选；列表展示为「老师、学生」「老师」「学生」等组合文案。

#### 场景：去掉「全部」选项
- **当** 用户在设置原因弹框中配置适用人员类别
- **则** 不提供「全部」选项，仅提供老师与学生

#### 场景：默认双选
- **当** 用户新增原因且未修改适用人员类别
- **则** 默认勾选老师与学生

#### 场景：休学/退学原因按端过滤
- **当** 老师或学生端打开休学/退学申请表单的原因下拉
- **则** 仅显示 `applicablePersonnelCategories` 包含当前 `applicantMode` 的原因项
