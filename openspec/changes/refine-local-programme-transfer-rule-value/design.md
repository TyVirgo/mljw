# 设计

## MR001/MR002 申请时间

| id | 申请时间列 | 规则值 | 判断逻辑 |
|---|---|---|---|
| MR001 | - | N（默认 3） | 开学后第 1~N 周内可提交 |
| MR002 | - | N（默认 1） | 开学后第 1~N 周内可提交 |

## 与其他规则对比

| 规则 | 规则值含义 | 申请时间列 |
|---|---|---|
| MR001/002 | 截止周 | - |
| MR004 | 0/1 是否允许 | 5~7（固定窗口） |
| MR005 | 0/1 是否允许 | - |

## 迁移

当 fallback 的 `applicationWeek` 为 `null` 时，`normalizeCondition` 强制返回 `null`，忽略旧 localStorage 中的 `{1,3}` / `{1,1}`。
