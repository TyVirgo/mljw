# 选课管理-模块壳层与信息架构

> 本变更包由同菜单下多个历史 OpenSpec 变更合并而成，供后续整理需求文档使用。实现状态以原型代码为准；本包作为需求沉淀，不重复驱动增量开发。

## 背景与动机

选课（Course Registration）是马来本科教务调研中规则最复杂、人工负担最重的环节之一，涉及 Excel 导表、M1/G1 与 Add/Drop/Retake 多平台割裂、复学/转学分补选及学分合规人工核对等痛点。本包覆盖模块整体建设、管理端信息架构重排、页面布局统一及批次配置能力扩展，便于按壳层与 IA 编写需求文档。

## 能力范围（按逻辑分组）

### 1. 选课模块整体建设

- 新增 Course Registration 模块骨架：学生端与管理端菜单、路由、演示数据与页面占位逐步替换为可演示功能。
- 原型讲解类说明统一标注「正式页面去掉」；轮次说明等改用 `CourseRegistrationCallout`（info），与其它页搜索上方提示一致。

### 2. 管理端菜单信息架构

- 管理端一级菜单改为四段：**批次与规则** / **选课过程** / **例外名单** / **结果与日志**（对齐第 7–9 次调研划分）。
- 收敛特殊申请相关菜单：屏蔽白名单；取消独立「例外」分组；补注册并入过程组。
- 侧栏去掉「选课报表」（`cr-report`）；页面与 demo 暂留便于日后恢复。

### 3. 页面说明与布局统一

- 选课模块全部相关页移除内容区顶部身份/徽章条（`ModuleBriefPanel`），「页面说明」收至面包屑行最右。
- 在线选课移除批次名与轮次说明 `page-note`，轮次操作说明写入 `crs-register` 页面说明。
- 学生端列表页统一顺序：提示 callout（含加退课演示周同行）→ 搜索区 → 操作按钮 → 表格/分页；去掉与菜单/面包屑重复的区块标题。
- **多行搜索（增量）**：`list-page-search` 首行查询/重置顶对齐；可折叠次行默认展开（与学籍列表搜索一致）。
- **列表分页（增量）**：选课管理菜单各主页面（含学生端落地页）表格默认每页 **20** 条；弹窗/抽屉内分页可不改。
- **补注册编辑（增量）**：补注册详情/编辑抽屉表单与 footer 按钮样式对齐选课批次抽屉（勾选行、取消/保存）。

### 4. 管理端课程容量与专业范围

- 管理课程总容量区分新生/老生配额；导入时写入初步拆分与源最大容量；支持按源最大容量百分比批量调整当前总容量。
- 容量设置旁增加「专业范围设置」：先勾选课程，弹窗批量设置可选专业范围，主表一眼可见当前限制。

### 5. 批次范围多选与术语统一

- 学生范围维度（学院/专业/批次）改为多选（数组存储）；学院增加「全部」；「轮次」改「选课轮次」，「各轮共用」改「全部轮次」。
- 学生可见列表列头统一为「课程分组」（在线选课、选课结果、我的选课等）；模块说明一级标题括号提示换行且文案缩短。
