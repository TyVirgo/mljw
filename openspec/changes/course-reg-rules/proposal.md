# 选课管理-选课规则

> 本变更包由同菜单下多个历史 OpenSpec 变更合并而成，供后续整理需求文档使用。实现状态以原型代码为准；本包作为需求沉淀，不重复驱动增量开发。

## 背景与动机

将「选课管理-选课规则」相关的零散提案合并为一份连贯需求说明，便于按菜单编写正式需求文档，并减少 openspec/changes 目录噪音。

## 能力范围（按逻辑分组）

### add-registration-rule-settings

**动机**

选课管理缺少校级「选课规则设置」入口。长/短学期选退窗口、学分上下限、复学上限、先修强制校验等目前散落在批次默认值与硬编码中，教务无法集中查看与调参。

**变更要点**

- 在「批次与课程」下新增 **选课规则设置**（`cr-rules`）

### polish-credit-rule-numbered-lines

**动机**

学分规则两条提示用「·」挤在一行，复学规则不易扫读；编号分行后字号也需一并加大便于扫读。

**变更要点**

- 常规 / 复学学分规则分行展示，前缀 `1.` / `2.`

### replace-registration-rules-simple

**动机**

选课规则设置页仍是长短学期/学分/先修模型，与产品图示的启用+名称+单规则值六条规则不一致。

**变更要点**

- 规则表改为三列：是否启用、规则名称、规则值

### sync-registration-rules-catalog（增量 2026-07）

**动机**

设置页 7 条旧目录与批次「②选课规则」图示不一致。

**变更要点**

- 总规则改为 5 条：关联先修、不及格可重修、可退自选（每轮次数）、允许超过最高学分、延迟缴费天数（保留）
- 去掉冲突/未缴费/未注册/修读对象等；退选两行合并为一条
- 三列表格形态不变；批次勾选子集留后续
