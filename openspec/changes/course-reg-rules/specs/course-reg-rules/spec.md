# 选课管理-选课规则 规格（合并）

## 说明

以下为各历史 delta spec 原文按来源拼接并做术语中文化处理。整理正式需求文档时，应按场景重写为「用户故事 / 验收标准」，消除重复与过时条目。

## 来源 `add-registration-rule-settings` / 能力 `course-registration`

## ADDED Requirements

### Requirement: 选课规则设置菜单
系统 必须在管理端「批次与课程」分组中提供「选课规则设置」菜单项。

#### Scenario: 侧栏入口
- **WHEN** 管理端用户展开「批次与课程」
- **THEN** 可见「选课规则设置」，点击进入规则页（非建设中）

### Requirement: 选课规则列表与编辑
系统 必须以表格展示校级选课规则，支持启用开关与行内编辑数字（及先修豁免标记）参数；默认规则 必须全部启用。

#### Scenario: 预置五条规则
- **WHEN** 用户首次打开选课规则设置
- **THEN** 可见长学期窗口、短学期窗口、常规学分上下限、复学学分上限、先修强制校验共五条，且均为启用

#### Scenario: 调参保存
- **WHEN** 用户编辑某条规则的可调参数并保存
- **THEN** 参数更新并持久化；非法数字被拒绝并提示

#### Scenario: 关闭规则
- **WHEN** 用户关闭某条规则的启用开关
- **THEN** 该规则标记为未启用（演示存储更新）

## 来源 `polish-credit-rule-numbered-lines` / 能力 `course-registration`

## ADDED Requirements

### Requirement: 学分规则分条编号
在线选课顶栏学分规则 必须将常规学生与复学学生两条说明分行展示，并分别以 `1.`、`2.` 编号。两条说明 必须使用同一字号，且 必须较原先单行提示字号大一号。

## 来源 `replace-registration-rules-simple` / 能力 `course-registration`

## ADDED Requirements

### Requirement: 选课规则三列六条
选课规则设置页 必须展示图示口径的规则行（含关联先修、重修、可退自选、超学分、延迟缴费、第三轮选课新老生名额互释等），表格列 必须仅为是否启用、规则名称、规则值；必须NOT 再展示学期类型、适用范围、多字段参数编辑与操作列；必须NOT 在表外另以独立卡片展示互释开关。

### Requirement: 规则值约束
布尔语义规则的规则值 必须仅为 0 或 1；「退选次数」必须为非负整数。

### Requirement: 学分提示不依赖旧规则行
学生在线选课顶栏学分说明 必须使用固定学分常量展示，必须NOT 依赖已移除的 CR003/CR004 规则行。

## 来源 `align-ge-me-senior-freshman-model` / 能力 `course-registration`

### Requirement: 第一轮权重与第三轮互释校级区
选课规则设置页 必须 在规则表中提供「第三轮选课新老生名额互释」一行（flag，默认开启），与其它校级规则同表展示，必须NOT 另起独立卡片或抽签参数区。第一轮衰减系数 r 与 ME 年级份额 必须NOT 在校级规则页配置（改由批次管理轮次 · 老生第一轮配置）。

#### Scenario: 校级默认开启

- **WHEN** 用户首次打开选课规则设置
- **THEN** 「第三轮选课新老生名额互释」 必须 出现在规则表中且为开启

#### Scenario: 无独立互释卡片

- **WHEN** 用户打开选课规则设置
- **THEN** 必须NOT 在规则表下方另见「第三轮名额互释」独立卡片

#### Scenario: 无校级 r

- **WHEN** 用户打开选课规则设置
- **THEN** 必须NOT 出现 GE/ME 全局衰减系数 r 的编辑控件
