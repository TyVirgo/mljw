# 变更：align-ge-me-senior-freshman-model

## Why

选课老师明确：GE/ME 选课须按「新生（第 1 学期注册）/ 老生（已第 2 学期上课）」区分时间窗与名额池；名额按人数比例初分并可手调；第一轮在老生名额内加权随机（毕业生优先、可配 r、到点自动发布）；二/三轮先到先得且第 3 轮互释对方预留池；学生精确到组并卡该学期 GE/ME 学分上限。现有原型仅有一套三轮时间、名额字段偏只读、第一轮偏人工确认，口径不符。本变更在**不新增侧栏菜单**的前提下，基于现有批次/管理轮次/管理课程/规则设置/选课结果/在线选课全量落地上述点（可分期交付，但验收不得砍项），且新增 UI 须与选课模块全局样式一致。

## What Changes

### 身份与范围

- 明确选课对象为 GE/ME；流程指引与批次说明对齐。
- 新生/老生按**注册学期序号**定义（demo 可落地判定字段）；文案替换「仅学期大于 X」的含糊表述为与定义一致。

### 名额（管理课程）

- 新/老名额可编辑；提供「按人数比例初分」（先对老生比例四舍五入，新生 = 总额 − 老生）。
- year2/sem2 才可选课：新生名额为 0（规则或课属性 + tip）。
- 展示实时新/老已选占比；往期占比以课详情/抽屉 demo 表体现（不新开菜单）。
- 支持手调二次分配；第 3 轮互释对方预留池的开关与行为（原型 mock）。

### 时间（管理轮次）

- 同一批次内分 **老生 / 新生** 两套 R1–R3 起止时间（每学年学期随批次配置）。
- 允许新生 R1 与老生 R2 尾重叠；同受众内顺序校验。
- 老生 R1 配置「结果发布时间」；双方 R3 对齐的 tip/demo。
- 批次列表轮次列可感知两套摘要；学生端按身份读对应窗口。
- **配置类与流水类时间均精确到时分秒**（秒默认 `00`）：轮次起止、结果发布、加退课/重修申请窗口的设置与展示；加退课/志愿等申请提交时间展示与写入同样带秒。列表新老受众标签为「新生：… / 老生：…」换行，不用单字「新」「老」。

### 学生选课规则

- 继续精确到教学组。
- 卡该学期 GE/ME 学分上限（学生上下文 demo 字段 + 提交校验）。
- 第一轮：同课多组最多中选一个分组。

### 第一轮出名单

- 容量取老生名额；毕业生（培养方案末学期仍有 GE/ME 口径的 demo 标记）100% 优先。
- 其余按 \(W_i = r^{N-i}\) 加权随机；规则设置默认 r（GE 倾向 3）、可改；ME 支持按专业覆盖表。
- 到结果发布时间（或一键「执行自动发布」）定稿；主路径无人干预，原「最终确认」降为可选异常口。

### 二 / 三轮

- 先到先得（保持并接受众时间窗）。
- R3：释放对方预留剩余名额（可手调）。

### UI

- 不新增侧栏菜单；扩现有抽屉/页。
- 新增块复用 callout、form-field、data-table、btn、DatePickerEn（含 datetime）等既有样式；中英 i18n。

## Non-goals

- 不新建「权重中心 / 名额分析 / 双日历」独立菜单页。
- 不重构加退课/缴费/补注册主流程（时间窗与提交时刻精度除外）。
- 不做生产级可复现审计抽签服务（原型本地 mock 即可）。
- 不接真实 Study Plan 服务（学分帽/毕业生用 demo 字段模拟）。
- 不把批次拆成「老生批 + 新生批」两套业务批次。

## 分期（不砍项）

| 阶段 | 内容 |
|------|------|
| Phase 1 | 身份文案与字段；双受众轮次时间；名额可编辑+比例初分+year2；实时/往期占比；流程指引 |
| Phase 2 | 学生按受众窗口；GE/ME 学分帽；R3 双向释放 |
| Phase 3 | 加权抽签+毕业生优先+r/专业表；同课组 R1 互斥；自动发布主路径 |
| Phase 4 | 轮次/申请窗/结果发布/提交时刻统一到 HH:mm:ss；列表新生/老生完整标签 |
| Phase 5 | 去掉在线选课身份/学分提示条；主表与批次列表行距收紧；批次名称不换行横滑，轮次仍两行 |
