# 变更：polish-result-round-dimension

## Why

管理端「选课结果 → 轮次维度」三轮 Tab 切换时，课程行与容量数字几乎不变：容量列读课库固定 enrolled，未按本轮名单；demo 行数也偏少。教务需要分轮可辨的已选/容量视图，并单独看到「不占培养方案容量」的特殊加课人数。

另：「第一轮志愿结果」与「轮次·第一轮」两套入口重复，教务既要看容量又要调志愿名单时需来回跳。需要收敛为「课程维度」并对齐在线选课的课×分组 rowspan 表。

## What Changes

### 已完成（容量口径）

- **分轮不同数据行**：同一批次筛选下，三轮展示的课程行集合不同；每轮过滤后至少 **25** 行，分页默认 **20** 条/页。
- **容量表头**：改为「有效最大/新生/老生容量（已选/总量）」；总量对齐管理课程容量；已选按本轮实选。
- **新列「特殊新加学生数量」**：可点开名单。

### 增量（信息架构融合）

- **顶栏改名**：「轮次维度」→「**课程维度**」；去掉独立「第一轮志愿结果」Tab；默认进入 **课程维度 → 第一轮**。
- **第一轮融合**：把原志愿结果的发布工具栏、志愿数量/老生容量、已选%、志愿名单操作，与容量三列+特殊新加合并到「第一轮选课」页。
- **表布局对齐在线选课**：同课多分组时，课公共列（序号/批次/代码/名称/类型/学分 + 容量三列 + 特殊新加）**rowspan**；分组列（分组名、志愿/老生容量、已选%、志愿名单）各行自展。复用 `sectionTableRowSpans`。
- **分页**：第一轮按**课**分页（非按分组行），避免 rowspan 被页切开。
- **第二/三轮**：仍保持一行一课的课级容量表（无志愿列）。

### 增量（R1 数字关联）

- **第一轮隐藏「新生容量」列**（R1 无新生参与）。
- **课级已选与志愿同源**：老生已选 = 各分组「选上」人数合计；有效最大已选 = 老生已选；有效最大总量 = 老生容量合计（口径 A）；特殊新加仍不计入已选分子。
- 分组列「志愿数量/老生容量」与课级老生/有效最大数字可对账，不再使用独立 round roster 乱数充当 R1 已选。

## Non-goals

- 不改学生维度主流程（「添加特殊学生」仍在学生维度）
- 不改 BatchCoursesDrawer 管理课程表头
- 不接真实选课统计 API
- 不要求三轮绑定不同选课批次
- R2/R3 不做分组 rowspan
