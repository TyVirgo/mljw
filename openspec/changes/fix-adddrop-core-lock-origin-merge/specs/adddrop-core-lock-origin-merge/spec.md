## ADDED Requirements

### Requirement: 换组锁原组按课号合并

加课及加退课选课弹窗判定本学期必修换组锁时，原分组上下文 MUST 合并「申请内拟退课」与「加课资格种子 `originalSectionCode`」：同一课号若已在拟退中出现，MUST 以拟退分组为准；其余课号 MUST 仍使用资格种子原组。MUST NOT 因存在任意一门拟退课而丢弃其他课的资格种子原组。

#### Scenario: 加退已选其他拟退仍锁 CHEM 异组

- **WHEN** 学生加退课已选拟退 MATH101（或任意非 CHEM 课），打开加课选课弹窗，资格种子 CHEM101 原组为 01，且无换组白名单命中 CHEM101-02
- **THEN** CHEM101 分组 01 可选（名额允许时）
- **AND** CHEM101 分组 02 不可选，状态说明为「本学期必修课默认不可换组重修。」

#### Scenario: 纯加课无拟退仍用种子

- **WHEN** 学生纯加课打开选课弹窗，CHEM101 原组种子为 01，无换组白名单命中 02
- **THEN** 分组 02 不可选并显示同上短原因
