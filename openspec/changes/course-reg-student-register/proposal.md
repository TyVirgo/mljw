# 选课管理-学生在线选课

> 本变更包由同菜单下多个历史 OpenSpec 变更合并而成，供后续整理需求文档使用。实现状态以原型代码为准；本包作为需求沉淀，不重复驱动增量开发。

## 背景与动机

学生在线选课是选课模块的学生主路径，覆盖轮次切换、课程检索、分组选择、先到先得队列与选课履历。历史变更从双栏布局、志愿制预选逐步演进为统一真选课模式，并打磨列表、工具栏与队列体验。本包按学生选课链路重组，便于写需求文档。

## 能力范围（按逻辑分组）

### 1. 模块入口与轮次/类型导航

- 选课模块默认落地页改为在线选课（`crs-register`）；立即选课后跳转「本轮选课情况」而非选课历史。
- 顶区第一行「学年学期轮次」下拉，第二行「公共选修 | 专业选修」Tab，切换对应批次上下文；demo 保证一二轮可操作、关闭轮次整页提示。
- 轮次时间条仅保留预选 / 正选 / 补选三卡，移除 Add/Drop 窗口卡片（加退课经侧栏专用页进入）。
- **选课轮次样式（增量）**：下拉保持按文案测宽不截断；标签与控件垂直对齐；选中文字色略降为 `#374151`，弱化为上下文切换而非重筛选控件。
- **批次优先导航（增量）**：
  - 先选「选课批次」，再选「选课轮次」；批次下拉仅含进行中（`active`），不含未发布/已结束；默认选中可选项第一条。
  - 选中批次后：按批次 `type` 只展示对应选修类型 Tab（另一类直接隐藏）；按轻量 demo 字段自动选中「进行中」轮次。
  - 轮次下拉只出现已配置起止时间的轮次；未设时间不出现。
  - 已过轮次（demo 标记）可切换查看，仅禁用「立即选课」；选课篮等其它操作保持可用。
  - 学分规则 Callout（图示1）移到类型 Tab 与课程主表之间。
  - **GE 批次 demo（增量）**：学生端可选 GE 批按 HUM/BUS/MPU 命名（对齐管理端 `Major Elective Selection (…) for {CODE} …` 句式）；各批挂不同课表与轮次 demo 状态，切换后列表内容不同。
  - **操作列（增量）**：全部轮次去掉「详情」；不在选课窗口的轮次隐藏整列「操作」。
  - **操作列统一（增量）**：选课窗口内每行均展示提交按钮；不可提交时按钮置灰，左侧感叹号 tip 说明原因（含已志愿/已选/排队中）；无 tip 时左侧仍占位，保证提交按钮纵向对齐。
  - **去掉类型 Tab（增量）**：批次已绑定选修类型，不再展示公共选修/专业选修 Tab；课表仍按批次 type 过滤与列差异展示。
  - **窗外本轮选课情况（增量）**：不在选课窗口时列表不展示「排队中」；「待分配」等仍只读展示；抽屉去掉操作列；状态列贴右不遮挡。
  - **第一轮志愿容量展示（增量）**：主表容量列改为「志愿数量/课程容量」；未满绿、满额～超额一倍内黄、超额一倍以上红；学生提交志愿不因容量拦截（仍排队至待分配）。

### 2. 在线选课列表与分组展示

- 主表按「一门课有几个课程分组就几行」展开，不合并分组；课程名称后增加「教学分组」列汇总全部分组名称。
- 「已选/容量」列采用色值与半圆角胶囊样式（`border-radius: 999px`）；「名额状态」口径改为已选人数/容量，与分组选择器一致。
- 查询区去掉「选课资格」筛选项；「预计需修 GE」统计移至管理端选课结果页（学生端顶栏只保留学分规则一行展示）。
- **专业选修校选类别（增量）**：ME 表增加「校选类别」列（文/商/理），枚举对齐基础信息 `schoolElectiveCategory`；原型混杂展示、暂不按学生过滤；表头 tooltip 说明正式需按学生所属类别过滤对应专业选修。
- **Tab 大类收口（增量）**：专业选修 / 公共选修 Tab 仅展示对应 `course.type`；误挂在 ME 批次的 GE demo 课迁入 GE 批次；ME 行校选类别必填展示（不可为 —）。

### 3. 立即选课与分组选择

- 预选/正选/补选统一：立即选课 → 选分组 →「确认选课」→ 选课队列（先到先得占容量，非志愿篮）。
- 分组弹层由卡片改为列表/表格（对齐「我的选课」）；学分要求 Callout 单行展示、字号略大更醒目。
- 分组表具备选择控件与容量色差，表头与数据字号区分；COMP3192 等 demo 分组补齐。

### 4. 选课篮、工具栏与学分提示

- 去掉右侧常驻双栏布局，搜索区与课程表占满一行；选课篮改为查询与列表之间的数量按钮，点击展开详情。
- 工具条左侧展示必修/选修 已修/要求进度；选课篮旁 tip 左对齐后向右展开，避免左缘裁切。
- 选课篮每条课程卡片排版对齐 `CourseSectionCard`：圆角边框、分组标题行、两列字段（任课教师/起止周/上课时间/上课地点）及字段 tip。

### 5. 选课队列与结果反馈

- 队列弹层改为「已等待 N 秒」递增；排队/结果不因计时结束自动关闭（用户关闭或取消排队）。
- 排队结束后：仅当选课队列 overlay 仍打开时展示结果页；已关闭则静默收尾。
- 失败/取消的「再次选课」不从本轮选课跳回选课；入口文案区分「本轮」与「历史」。

### 6. 我的选课履历

- 「我的选课」改为表格：序号、课程代码、课程名称、学分、分组名称、任课教师、起止周、上课时间、上课地点、状态、操作。
- 工具栏按钮蓝底白字，文案「我的选课({n}门)·已选{credits}学分」；支持查看进度 / 退选 / 再选一次，确认选课后仅轻提示入队（不自动弹出全屏队列）。
- 支持批量退课与横滑冻结列；排队中可从表格取消。

### 7. 列表交互与视觉修复

- 学分漏斗可点击展开/收起，过滤面板不被数据行挡住；不可选原因 tip 完整可见；热门标签移除；排队中行勾选列语义清晰。
- 已满课不可候补（与当前产品一致）；退课需确认防误操作。

### 8. 课程组 / 课表预览 / 时段排序（增量 2026-09）

- ME「课程组」列：`Group{n}` 左对齐；`(Intake:…)` 仍单独下一行；两行在单元格内上下居中。
- 「上课时间地点」多段按 **周一→周日、早→晚** 排序后展示（与课表解析同源）。

- 虚线课块若与其它课块时段重叠：右上角橙色 `!` + 与本轮选课情况相同的冲突 tip（`clashRowTip`）。

### 9. 退选按教学分组（增量 2026-09）

- 「本轮选课情况」/选课篮退选：只移除**该行**对应的教学分组（`courseId + sectionId`），同课其它分组保留。
- R1 待分配与 R2/R3 已选成功同一口径；撤销管理端志愿态亦按分组。
- 志愿拖拽调序键改为行级（课+分组），避免同课多组互相覆盖。

### 10. R2/R3 可选名额展示（增量 2026-09）

- R2、R3 主表/筛选/分组选择器：原「已选/容量」改为「可选名额/总名额」。
- **总名额** = 现有分组 `capacity`（涵盖老生+新生）。
- **可选名额** = 当前学生类别剩余可选：R2 为本池剩余（老生 cap−已选 / 新生 cap−已选）；R3 在新老互释开启时为两池剩余之和。
- R1 展示不变。选课判满与展示口径对齐（有可选名额才可选）。

### 11. 入口时间轴「查看课程 / 进入选课」（增量 2026-09）

- **查看课程**仅出现在 R1：未开始（pending），或 R1 已结束且 R2 仍待开放（公布结果～R2 开始前）。

- R2/R3 待开放 → 不展示「查看课程」；仅开放时「进入选课」。
- `demoActiveRound: null` 表示当前无开放轮（不回退到第一轮）。
- 学生入口同专业 GE/ME 各 **4** 档 demo（按时间序）：R1 未开放 → R1 进行中 → R2 → R3；R1 未开放置顶（`demoCatalogPhase`）；未开放批通过 `demoCourseSourceBatchId` 复用即将开选的 R1 课表（只看不选）。
- R1 未开放「查看课程」= 正式 R1 只读预览：课程信息与 ME 课程组列/排序/底色对齐正式页；**必须NOT** 展示容量/已选百分比列与操作列。
