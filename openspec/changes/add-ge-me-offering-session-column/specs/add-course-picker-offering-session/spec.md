## 新增需求

### 需求：加课 GE/ME 上课学年学期列

加课选课弹窗在「公共选修」「专业选修」Tab 下，MUST 在「可选名额/总名额」前展示「上课学年学期」列；该列 MUST 始终显示（不依赖白名单开关）。表头 MUST 提供 tip，说明默认展示当前学年学期课程，以及白名单允许未来选修时按学年学期从前到后排序。

#### 场景：打开公共选修 Tab

- **当** 学生打开加课选课弹窗并切换到公共选修
- **则** 表头可见「上课学年学期」（带 tip），且位于名额列之前；行内展示该课开课学年学期（缺省时为当前申请学期）

#### 场景：多学期列表排序

- **当** 列表中存在不同上课学年学期（如含未来学期选修）
- **则** 行按学年学期字符串升序排列（`2025/09` 先于 `2026/04` 先于 `2026/09`）
