## 修改需求

### 需求：查询列表行操作为只读
系统应在异动查询列表上仅提供只读适用的行操作。「详情」应打开合并申请详情内容与审批日志表格的统一抽屉。

#### 场景：查询行操作
- **当** 用户查看异动查询列表行的 Actions
- **则** 仅「详情」可用于查看申请内容与审批历史，且 Approval Log 不是独立操作

#### 场景：带脱敏的查询详情抽屉
- **当** 用户从异动查询打开「详情」
- **则** 抽屉先展示只读详情字段、再展示底部审批日志表格，且详情区敏感护照或 IC 字段脱敏

#### 场景：查询不进入整页审阅
- **当** 用户从异动查询打开「详情」
- **则** 查询列表在抽屉后方保持可见
