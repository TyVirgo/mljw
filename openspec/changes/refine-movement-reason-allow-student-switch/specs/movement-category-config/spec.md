## 修改需求

### 需求：异动原因以「是否允许学生申请」开关配置

设置原因列表与编辑弹框应将原「适用人员类别」改为「是否允许学生申请」开关，轨道上显示是/否字样；新增原因默认关（否）。

#### 场景：列表列展示开关
- **当** 用户打开异动类别设置原因弹框
- **则** 第四列表头为「是否允许学生申请」，单元格为是/否开关而非老师/学生文案

#### 场景：列表行内切换
- **当** 用户在列表中点击某原因的开关
- **则** 系统立即保存并更新该原因的可见范围

#### 场景：编辑弹框开关
- **当** 用户新增或编辑原因
- **则** 以开关配置是否允许学生申请，不再提供老师/学生多选

#### 场景：默认关
- **当** 用户新增原因且未操作开关
- **则** 默认为否（仅老师端可见）

#### 场景：申请端过滤不变
- **当** 老师或学生端打开休学/退学原因下拉
- **则** 仍按是否允许学生申请过滤可见原因项
