# 学籍管理-异动申请（教职工/学生端）

> 本变更包由同菜单下多个历史 OpenSpec 变更合并而成，供后续整理需求文档使用。实现状态以原型代码为准；本包作为需求沉淀，不重复驱动增量开发。

## 背景与动机

学籍异动申请是教职工代学生发起、或学生本人自助发起的核心入口，覆盖转专业、休学、复学、退学四类场景。历史迭代从占位页逐步补齐完整申请链路，并统一流转状态语义、表单分区、声明合规与双端入口。本包按申请业务链路重组，便于直接拆成需求文档章节。

## 能力范围（按逻辑分组）

### 1. 四异动申请与统一流转状态

- 转专业、休学、复学、退学均提供申请历史列表、多 Section 申请表单及完整流转状态（草稿编辑、审批中撤销、打回修改、终态只读）。
- 每态均有 Mock 样例；流程日志外置至列表 Actions，详情 Modal 只读展示申请内容（不含审批操作区）。
- 管理端进入默认 Tab 为转专业（`programme-transfer`）；学生端同理。

### 2. 教职工代申请与学生自助双入口

- 管理端：可搜索分页的 **学生选择器** 代学生发起申请（替代「查询 + 全量下拉」）。
- 学生选择弹框表格增加 **专业层次** 列；四类异动（转专业/休学/复学/退学）共用同一弹框，原型演示阶段单元格统一展示「本科」（英文 `Undergraduate`，不按学籍真实层次分化）。
- 选择学生表格在姓名与专业之间增加 **国籍** 列，取值自 `basicInfo.nationality`；中文界面经 `tr()` 显示对应国家中文名，英文界面显示英文国名；空值显示 `—`。
- 选择学生表格去掉列宽截断省略号，表格设 `min-width`，容器保持横向滚动，长专业名等字段可左右滑动看全。
- 学生端：学号/姓名等自动填充且不可选他人，从学籍模块自助申请。
- 申请详情与审批职责分离：转专业 Section VII（教务专用）仅审批侧维护，申请 FormModal 移除该区块。

### 3. 表单分区与学生信息区

- Section II（学生填写）、Section III（家长同意，复学/转专业无）、Section IV（支持性文件）字段顺序与标题按产品原型统一。
- Section I 统一展示学生 Visa Expiry Date：China/International 显示 IO 维护的日期范围，Local 显示占位符。
- 四异动补充「目前所在学期」只读字段，与「申请学年学期」同排；退学「目前所在地」改为下拉 `In Campus` / `Out of Campus`。
- 正常流程顺序：填写信息 → 上传附件 → 勾选声明 → 提交（声明区块移至附件之后，Section 重编号）。

### 4. 休学期间与学期日期联动

- 「休学期间（YYYY/MM）」下拉旁增加 `?` tooltip，说明可选申请日期之前（休学补回）与之后的学期。
- 选定期间后只读展示「休学开始时间」「休学结束时间」（dd/MM/YYYY），随 `semesterInfo` 联动并持久化；学籍状态日志休学备注体现日期区间。
- 休学期间选项按学年学期 **倒序** 排列（新的在前），占位「请选择」仍置顶。

### 5. 家长联系人与学生声明

- 选学生时从 `student.family[]` 映射全部非空联系人为 `parentContacts[]` 快照；Section III 监护人字段 **全部只读**（申请内不可改、不可增删），标题旁 tip 说明规则；档案无监护人时禁止提交。
- 四异动 Section V 声明：通用句 + 各类型专属条款（休学/复学修业年限、转专业规章与签证、退学仅通用句），连续编号；通用句后新增家长/监护人邮件通知告知（中英文同步）。
- 四类型 FormModal 均含声明区 + 必填勾选（复学保留双勾选）；移除「下载家长同意书」按钮（家长信息字段保留）。

### 6. 国际生说明与附件

- Applicant Notes 下方增加国际说明（仅 `International` 类别）；复学可选康复记录等扩展材料，替代单一 attachment 与一行 isaoNote。
- **退学附件（按国籍）**：马来西亚——同意书*、住宿退宿表、病历、其他附件（**无**机票）；中国——同意书*、住宿退宿表、机票*、**中国身份证正面&反面***（单槽，位于病历之上）、病历、其他附件；其他国籍——保持原国际生清单（同意书*、住宿退宿表、机票*、病历、其他附件）。标签中/英随界面语言切换。管理端与学生端共用同一表单组件。休学/复学附件逻辑不变。切换学生时清空已传附件并提示。
- **休学附件（图示1–3，按国家）**：马来西亚 / 中国 / 其他与退学国家顺序一致；图1 马来为同意书* + 病历（可选）+ 其他附件；图2 中国与图3 其他为同意书* + 病历（可选）+ 机票 + 其他附件。管理端与学生端共用 `DefermentFormModal`，随学生国籍切换清单；切换学生清空附件并提示。
- **复学附件（图示1–3，按国家）**：国家顺序同上；图1 马来为医疗康复证明（可选）+ 其他附件；图2 中国与图3 其他为签证相关材料* + 医疗康复证明（可选）+ 其他附件。无同意书/机票。管理端与学生端共用 `ResumptionFormModal`；切换学生清空附件并提示。

### 7. 退学与转专业专项

- 退学 Section II 新增必填「是否完成本学期期末考核」（Yes/No），标签旁常显 tooltip；选 Yes 时期末出勤日默认为本学期 Exam week 最后一天，允许用户再改。
- 审批通过的转专业申请写入 Status Log 备注，对齐 legacy「学籍异动说明」格式（审批通过学年学期与生效学年学期；转专业不改学籍状态 `modifyStudentStatus: false`）。

### 8. 全链路日期格式统一

- 异动全链路（四 Tab 申请 → 审批 → 维护 → 查询 → 统计 → Export / Approval log）日期字段统一展示为 `YYYY-MM-DD`（如 `2025-09-20`）。
