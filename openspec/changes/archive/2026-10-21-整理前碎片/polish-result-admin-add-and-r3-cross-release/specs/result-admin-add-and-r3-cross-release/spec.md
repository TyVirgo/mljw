## ADDED Requirements

### Requirement: 选择学生表头可一键全选筛选结果

「选择学生」弹窗表格表头复选列 MUST 提供全选控件；勾选后 SHALL 选中当前筛选条件下的全部学生（含跨页），取消勾选 SHALL 清空本次勾选。

#### Scenario: 表头全选当前筛选结果

- **WHEN** 管理员打开「选择学生」且查询结果多于一页
- **THEN** 表头复选框勾选后，当前筛选结果中所有学生均被选中（不限当前页）

#### Scenario: 取消表头全选

- **WHEN** 表头全选处于勾选状态且管理员取消勾选
- **THEN** 所有已勾选学生被清空

### Requirement: 学生维度可按课程来源筛选

选课结果「学生维度」搜索区 MUST 提供「课程来源」条件；查询时 SHALL 仅保留 `courseSource` 与所选值匹配的结果行；选「全部」或不选时不按来源过滤。

#### Scenario: 按课程来源过滤

- **WHEN** 管理员在学生维度选择课程来源为「代选」并查询
- **THEN** 列表仅展示 `courseSource` 为 admin 的行

### Requirement: 代选须填写原因并可上传附件

「新增学生选课」弹窗 MUST 提供必填「原因」与可选「上传附件」；未填原因时 MUST 阻止确定；确定成功后 SHALL 将原因及附件元数据写入代选结果数据。

#### Scenario: 缺少原因不可提交

- **WHEN** 管理员已选课程与学生但未填原因并点击确定
- **THEN** 系统提示原因必填且不写入代选结果

#### Scenario: 带原因与附件提交

- **WHEN** 管理员填写原因并可选选择附件后确定
- **THEN** 代选成功且结果数据包含原因；若有附件则包含附件文件名等元数据

### Requirement: 第三轮工具栏展示互释时间

课程维度且当前轮次为第三轮时，工具栏导出按钮旁 MUST 只读展示「第三轮名额互释时间」标签与当前批次解析得到的互释时刻；未配置时时刻显示为占位符（如 —）。

#### Scenario: 第三轮可见互释时刻

- **WHEN** 管理员在选课结果课程维度切换到第三轮选课
- **THEN** 导出按钮旁显示互释时间标签及 `resolveEffectiveCrossReleaseAt` 解析值（或 —）

#### Scenario: 非第三轮不展示

- **WHEN** 管理员处于课程维度第一轮或第二轮
- **THEN** 工具栏不展示互释时间文案
