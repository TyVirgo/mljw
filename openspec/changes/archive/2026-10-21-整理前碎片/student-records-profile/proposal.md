# 学籍管理-学生基本信息

> 本变更包由同菜单下多个历史 OpenSpec 变更合并而成，供后续整理需求文档使用。实现状态以原型代码为准；本包作为需求沉淀，不重复驱动增量开发。

## 背景与动机

学生基本信息是学籍管理的核心档案菜单。历史迭代覆盖了完整 CRUD、列表检索、国籍/类别推断、入学信息级联、签证到期展示、详情日志与变更记录、预览登录与导出入口等。本包按**业务逻辑**重组，便于直接拆成需求文档章节。

## 能力范围（按逻辑分组）

### 1. 档案维护（增删改查与导入）

- 提供学生档案列表及 New / Edit / Import / Details 完整演示能力（七 Tab 表单）。
- 字段标签统一注册（表头、搜索、详情同源），避免中英混排。
- 演示数据补齐 Programme Structure、注册时间、预计毕业批次、欠费等列，支撑筛选演示。
- 国籍选项不含「台湾 / Taiwan」。

### 2. 列表检索与展示

- 搜索区按字段拆分：学号、姓名、中文名、IC、手机（可组合精确筛）。
- 支持多维度下拉筛选；主表展示国籍、欠费、学籍状态等；横向滚动时冻结序号/学号/姓名。
- 学籍状态旁展示「学籍类型」（Track Category），与异动回写字段对齐；不单独做筛选项。

### 3. 新建/编辑：国籍优先与入学信息级联

- 抽屉改为「国籍优先」：先选国籍，再按规则推断学生类别并展示对应字段（与异动侧推断逻辑一致）。
- 学籍信息 Tab 字段顺序：**专业 → 专业代码 → 专业层次 → 学院**（选专业后自动带出其余）。

### 4. 签证有效期（学生 Pass）

- China / International：基本信息只读展示 IO 维护的签证有效期（仅截止日期，dd/mm/yyyy）。
- 列表与异动申请相关展示同样只显示截止日期；搜索仍可用日期区间过滤。

### 5. 详情扩展与运维入口

- **状态日志**：毕业终态（完成/毕业批次与日期）及退学结构化备注（原因对齐 WDR001）。
- **信息变更记录** Tab（在状态日志右侧）：展示学工侧基本信息/住宿字段变更对比（字段、从→到、时间、操作人）。
- 详情 footer「导出学籍卡」入口（本期仅按钮，不实现导出逻辑）。
- 列表操作列 **Preview**：以该生身份进入学生自助端验证体验。
