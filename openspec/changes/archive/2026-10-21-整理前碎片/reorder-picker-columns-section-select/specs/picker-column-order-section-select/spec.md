## ADDED Requirements

### Requirement: 白名单选课弹框学分列在课程分组之前

白名单「选择课程豁免先修课」与「选择未来学期必修课分组」（及同源换组选课）弹框表格 MUST 将「学分」列置于「课程分组」列之前；学分仍为课级合并单元格，课程分组仍为分行单元格。

#### Scenario: 列顺序可见

- **WHEN** 管理员打开白名单选课弹框且列表有同课多分组合并行
- **THEN** 表头顺序为课程代码、课程名称、学分、课程分组、任课教师、上课时间地点

### Requirement: 加退课选课弹框一级字段在前二级在后

加退课「选择课程」弹框（必修 / GE / ME）MUST 将课级合并列排在分组分行列之前：序号、代码、名称、（可选）课程组、学分、类别、（可选）原上课学期在前；课程分组、任课教师、起止周、上课时间地点及后续分行状态列在后。

#### Scenario: 必修 Tab 列序

- **WHEN** 学生打开加课选课弹框且处于必修课 Tab
- **THEN** 「学分」「课程类别」「原上课学期」出现在「课程分组」之前，分组相关列在其后

### Requirement: section 模式可按课程分组独立勾选

当白名单选课 `selectionUnit` 为 section 时，多选框 MUST 出现在每个课程分组行（非课级合并）；允许同一课程下仅勾选部分分组；确认结果 MUST 仅为已勾选分组的 section refs。

#### Scenario: 同课只选一个分组

- **WHEN** 管理员在未来学期必修课分组弹框中对某课仅勾选其中一个分组并确定
- **THEN** 回写仅包含该分组的 section ref，不含同课未勾选分组
