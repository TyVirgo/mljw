## ADDED Requirements

### Requirement: 重修必修可不换组限制

重修及重修（退课）选课 MUST NOT 因「本学期必修默认不可换组」而禁用其他课程分组。

#### Scenario: 重修可选其他分组

- **WHEN** 学生在重修选课弹窗打开必修课且存在多个分组
- **THEN** 非原组分组不因换组锁而灰显或显示不可换组重修提示

### Requirement: 加课必修保留换组锁

加课及加退课申请中，本学期必修相对原分组换组 MUST 默认禁止，除非白名单允许换组且清单含目标分组；禁用说明 MUST 为「本学期必修课默认不可换组重修。」

#### Scenario: 加课异组灰显短提示

- **WHEN** 学生在加课弹窗选择本学期必修的其他分组且无换组白名单命中
- **THEN** 该分组不可选
- **AND** 状态说明为「本学期必修课默认不可换组重修。」
