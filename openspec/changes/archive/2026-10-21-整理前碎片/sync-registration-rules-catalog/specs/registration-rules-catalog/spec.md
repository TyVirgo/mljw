## ADDED Requirements

### Requirement: 选课规则设置目录与批次图示对齐
选课规则设置页 必须仍以三列表格（是否启用、规则名称、规则值）展示校级总规则。总规则 必须恰好包含以下五条，且顺序为此：关联先修课程；不及格可重修选课；可退自选课程（每轮次数上限）；允许超过最高学分；延迟缴费天数。系统 必须NOT 再展示是否允许课表冲突、学生未缴费不得选课、学生未注册不得选课、修读对象是否可选，以及拆分的「是否可退选」「退选次数」两行。

#### Scenario: 打开设置页见五条
- **WHEN** 用户打开选课规则设置页（无旧版存储或已升级存储）
- **THEN** 表格恰好显示上述五条规则名称，列仍为启用 / 名称 / 规则值

#### Scenario: 可退规则合并为一条
- **WHEN** 用户查看「可退自选课程」相关规则
- **THEN** 仅有一行：启用开关控制是否可退自选，规则值为每轮上限次数（非负整数）

#### Scenario: 延迟缴费天数仍可配置
- **WHEN** 用户编辑「延迟缴费天数」的规则值并失焦/变更
- **THEN** 新值持久化，且读取延迟缴费天数的演示接口返回该值（规则启用时）

#### Scenario: 布尔规则规则值约束
- **WHEN** 用户编辑关联先修 / 重修 / 超学分规则的规则值
- **THEN** 仅接受 0 或 1；非法值被拒绝并提示
