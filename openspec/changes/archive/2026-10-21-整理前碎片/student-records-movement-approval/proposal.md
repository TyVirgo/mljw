# 学籍管理-异动审批

> 本变更包由同菜单下多个历史 OpenSpec 变更合并而成，供后续整理需求文档使用。实现状态以原型代码为准；本包作为需求沉淀，不重复驱动增量开发。

## 背景与动机

学籍异动审批自申请侧独立出来后，需承载待我审批、历史审批、详情查阅、流程日志与教务代撤销等能力。历史迭代补齐列表字段、并行会签展示、详情时间轴与撤销入口收敛。本包按审批业务链路重组，便于写需求文档。

## 能力范围（按逻辑分组）

### 1. 审批模块独立建设

- 新增 **学籍异动审批** 菜单：与「学籍异动申请」拆分；申请详情已改为只读，审批 UI 从申请侧移除。
- 审批视角由登录身份决定（v1 固定默认角色），列表页不提供「Current approver role」手动切换下拉。

### 2. 审批列表与搜索

- 主表（`MovementApprovalView`）异动类别后新增：历史申请次序、最近审核时间（待我审批中取当前审批人前一逻辑节点操作时间；会签多分支取最新）。
- 搜索区标签与输入框同一行左对齐（对齐项目统一 `list-page-search.css`，非 column 换行布局）。
- 「审批阶段」列与时间轴节点标题展示具体部门名称（`formatApprovalStageLabel`：stage key → 部门展示名），非内部 Pending Review key。

### 3. 审批详情与流程日志

- 详情抽屉：**流程图在上、申请内容在下**（`ApprovalTimeline` + `buildMovementTimelineNodes`），与课程申请详情一致。
- 审批日志支持会签并行语义：**分支开始 → 多分支卡片 → 分支汇聚**（`getParallelGroups` 折叠）；Demo 含混态会签。
- 管理端申请详情支持导出 PDF（WYSIWYG）；附件区「支持格式」提示位于选择文件按钮下方 hint 样式。

### 4. 撤销入口收敛

- 管理端 **撤销**（Cancel）：收敛至「学籍异动审批 · 历史 Tab · In Progress 行」列表操作（含 tooltip 与确认弹框）。
- 「学籍异动申请（管理端）」与「学籍异动维护」列表保留 AC 代撤销；查询页不提供业务型撤销。
- 学生「取消」与教务「撤销」区分说明文案。
