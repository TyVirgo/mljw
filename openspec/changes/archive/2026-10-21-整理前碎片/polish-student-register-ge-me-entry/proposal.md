# 变更：polish-student-register-ge-me-entry

## Why

8.6 会议要求学生在线选课先分清「去哪选、哪一轮、学分进度」：历史轮仍可点回像 Bug；GE/ME 混在批次选择里缺少入口说明；毕业 GE 文/商/理进度被学期帽挤掉。本包只落地 A1/A2/A3，其余 backlog 下批。

列表落地后评审：批次/轮次下拉与课程库条占用过多纵向空间；轮次既已锁定当前轮，下拉（含置灰）仍像可操作。改为与「返回目录」同行的只读状态条，进度仅数字比。

## What Changes

- **A2**：在线选课首屏 GE / ME 分入口目录；点选后进入该类型选中批次列表
- **A1**：进入列表后自动落在当前开放轮；列表内批次名与轮次（含时间窗）**只读展示**，不可下拉切换
- **A3**：学期学分与文/商/理以 **已选/需求** 数字同屏展示（无进度条）；监控详情仍并列两段
- **列表顶栏**：`[返回目录] 批次名 · 轮次时间 | 当前类型分数 ·（GE 时）文商理分数 [课程一览]` 单行
- **修订（方案 B）**：
  - 入口/列表按类型过滤：GE 只露 GE；ME 只露 ME（+ 文商理）
  - 文商理归 ME 细分；demo 当前之和对齐 ME 当前，要求之和 = meMax
  - 目录卡「选课批次」下增加「选课轮次」下拉（方案 A：仅当前开放轮 + 起止时间）；截止标签改为「选课轮次截止时间」；选课说明不含「第 N 轮：」前缀
- **增量**：本轮选课情况表「课程分组」与「学分」列对调；选课入口页标题下增加学生基础信息条（学号、姓名、专业、年级，年级展示 `2024/09`）
- **增量 §12**：入口页「学生信息」在上、「选择选课入口」在下；列表顶栏批/轮下拉收窄靠左；课表课块字号+1、行高抬高减少抽屉空白
- **增量 §13**：顶栏批/轮下拉加宽防裁切；展示层新增「上课时间地点」拼接（底层 time/room/weekRange/meetings 保留）；在线选课主表与本轮情况用拼接列；课表预览展开多段；加退课只读展示用合并，选择带出仍用独立字段
- **增量 §14（顶栏/工具条重排）**：列表顶栏批/轮下拉靠左、返回入口贴右；「课程一览」在「本轮选课情况」与「我的课表」之间；学分胶囊在工具条最右。三操作按钮统一高度/字号（主按钮可保留实心蓝）。GE/ME 共用。
- **增量 §15（入口截止态 + GE 文商理）**：
  - 入口卡：轮次 `end` 已过 → 徽章「已结束」+ 关态底色；「进入选课」置灰；第一/二轮提示「等待下一轮选课开始」，第三轮提示「此批次选课已结束」（与 demo 开闭标志解耦，以日历截止为准）
  - GE 与 ME 同构：本学期总分胶囊下展示文/商/理细化（GE 配额之和对齐 geMax）；入口卡与选课列表工具条均展示
- **增量 §16（入口 CTA / 默认批）**：截止提示写入置灰按钮文案（不再单独一行）；同类型默认批次优先「进行中」（demo 开放且日历未截止），已结束批仍可下拉切换
- **增量 §17（GE/ME 轮次 demo 矩阵）**：
  - 学生端每种类型 4 条 `active` 批：第一/二/三轮各一条「进行中可选」，另一条「已结束不可选」（关窗钉第一轮，按钮「等待下一轮选课开始」）
  - 开闭只认 `demoActiveRound` / `demoClosedRounds`；轮次日期仅作展示，**不**随系统时钟把进行中批打成关窗
  - 已结束统一不能选：目录 CTA 置灰不可进列表；若列表内切到该批则只读并提示不在选课时间段内
  - 目录/列表同类型下拉含关窗批（进行中排前，默认选中进行中）
- **增量 §18（入口按专业过滤 + 三轮时间轴）**：
  - 同专业学生目录仅见本专业 GE/ME 批次；过滤其他专业
  - 选课批次下拉：同专业三档 demo（R1 进行中 / R2 进行中 / R3 进行中），对应时间轴状态 `(进行中,待开放,待开放)` / `(已结束,进行中,待开放)` / `(已结束,已结束,进行中)`
  - 去掉卡片级状态徽章、截止行、轮次下拉与系统时间倒计时；改为纵向三轮时间轴 + 状态胶囊（进行中/已结束/待开放）
  - 「进入选课」挂在「进行中」轮次行最右；仅该轮可进列表
  - 本学期学分上方增加毕业学分（同构胶囊，数字更大，多学期累计 demo）
- **增量 §19（学分求和 + 时间轴/教师打磨）**：
  - 演示叙事：本学期即第一次计分，无入学前已修；毕业已选 ≡ 本学期已选（分类与总分同步）
  - 总分已选/要求 = 文+商+理之和；修复 GE 本学期总分与分类脱节
  - 入口时间轴字号加大、圆点与轮次同行对齐
  - demo 课任课教师改为外籍姓名
- **增量 §20（列表去批轮条 + 面包屑返回 + 工具条重排）**：
  - **去掉**列表顶栏批/轮下拉整块；页内 **不允许** 切换批次与选课轮次（仅入口卡选定后进入）
  - 「返回入口」移至面包屑同一行最右侧；**仅** `crs-register` 去掉「页面说明」
  - 工具条（课程一览 / 我的课表 + 学分）：置于**搜索区下方、本轮选课情况上方**
  - 学分行：毕业学分（总分 + 文/商/理）整组在公共选修（或专业选修）本学期胶囊左侧同一行
- **增量 §21（学分文案 + 课号教学目标弹层）**：
  - 毕业学分胶囊文案改为「毕业学分要求(GE/ME)」；本学期类型胶囊改为「学期学分要求(GE/ME)」
  - 主表 / 本轮选课情况 / 课程一览课号均为蓝色可点；弹层在批次名与 Course Library 行之间插入该课教学目标表（图示4结构）；GE/ME 内容按课适配
- **增量 §22（课表块 / 抽屉条 / 入口时间轴）**：
  - 我的课表虚线「本轮选择」保持绿色虚线；课块展示齐全信息且内容上下左右居中；同格叠显不隐藏 meta
  - 本轮选课情况抽屉收口条去掉「还有 N 门 · 排队 M」，仅保留「展开更多」「收起更多」
- **增量 §23（入口时间轴公布附属行）**：
  - 志愿结果公布不作为独立时间节点；老生 R1 行下展示「志愿结果公布：{时刻}」
  - 时间轴仅三轮三个圆点，点与轮次标题行对齐，竖线连贯不断
- **增量 §24（课表行高均摊与左轴不换行）**：
  - 时段仍为 8:00–22:00 共 14 行；不新增 22/23 点时段
  - 将预览区底部约两行空白均摊进各行（行高约 44→50px），课块展示空间更大
  - 左轴时间段与课块文案统一 `nowrap`；所有 `WeekScheduleGrid` 引用处一致
- **增量 §25（GE 第四类 + 无 GE 专业入口）**：
  - GE 文/商/理之外增加第四类 **AI与开放选修**；入口/列表/加退课/监控等胶囊与列头统一展示「AI与开放选修」（不用短标签「AI」）
  - 培养方案 `geRequired === 0` 的专业学生：**不展示 GE 入口卡**，仅 ME 卡且左对齐（半宽）；demo 默认 SWE 仍双卡不变

## Non-goals

- 不做 G04 类别段
- 不做结果页「一页看清」(B3)、等待公示 (B1)
- 不做知情同意、学期级加退窗、抽签深化、缴费、白名单闸门策略、开课同步等
- 列表内不提供切批/切轮（demo 强制切轮另议）；切批仅在目录入口卡下拉
- 不模拟真实倒计时过期；不为新生单独再做一套跨专业 8 条批；§18 起同专业仅三档进行中 demo（不再在下拉放「全关窗」第四档）
- §19 不引入入学前已修学分模型
