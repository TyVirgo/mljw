# 变更：polish-whitelist-page-ux

## Why

白名单页（原补注册壳）文案大量露出 i18n key：`courseRegistration.whitelist.*` 被旧 BOA「白名单审批」同名块覆盖。列表无本页新增，权限列显示英文 key，与「可手工新增 + 监控写入」双来源口径不符。

## What Changes

- 拆分 i18n：现行突破限制白名单键保留 `whitelist`；旧 BOA 审批链改名为 `whitelistBoa`，并改未挂菜单旧页引用
- 白名单列表：Callout/列头/权限摘要正确中英；增加「来源」列；工具条「新增」
- 新增/编辑抽屉：选学生（仅新增）、勾选权限、填写有效时长/先修截止、备注；写入同一 `supplementListQueue`（`source: manual`）
- 监控加入路径保持不变（`source: registration-monitor`）
- 相关「补注册名单」跳转/推荐文案统一为白名单

## Non-goals

- 不实现 BOA 在线审批链
- 不改学生闸门默认「未邀请是否开门」策略（可另包）
- 不删除旧 WhitelistView 源码（仍不挂菜单）

## 增量（2026-09）：权限父子归类 + 先修豁免选择器

- 「补注册（窗外申请）」文案改为「允许加退课/重修申请」；勾选框可交互（取消默认置灰禁用）。
- 「可加课 / 可退课 / 可重修」为父项「允许加退课/重修申请」的子项：仅父项勾选时可勾；父项取消时子项禁用并清空。
- 先修豁免、突破最高/最低学分位置自适应两列布局。
- 先修豁免课号：改为「选择」按钮 + 多选课程选择器（可空=本学期加课均豁免）；展示已选课号标签。
- 先修豁免截止：改为学年学期选择器（`AcademicSessionMonthPicker`，`YYYY/MM`），不以时分秒计；有效期按该学期月末判定。
- `rebuildPermissionsFromForm` 不再强制永远写入 `supplement`；按父项勾选落库。

## 增量（2026-09）：表单与选择器 UX 打磨

- 先修豁免课程选择器：搜索「课程代码 / 课程名称」同一行左右排列；分页默认 20 条/页。
- 先修豁免课程与截止学年学期：抽屉内左右同一行。
- 邀请门有效时长：仅配置父项「允许加退课/重修申请」一行，默认 **48h**；不再按加/退/重修细分；保存时将该小时数同步到已开的子权限。
- 「保存后立即发送邀请」改为「保存后立即发送通知」，新增默认勾选。
- 新增白名单：选学生改为多选（标签回显对齐 `AdminAddStudentPickModal`）；保存时每位学生各写一行；已在名单者跳过并提示。

## 增量（2026-09）：权限文案 / 必填 / 列表 demo

- 去掉先修学期 hint 文案；「先修豁免」→「课程豁免先修课」；「先修豁免截止学年学期」→「先修豁免学年学期」。
- 去掉「突破最高学分」勾选；「突破最低学分」→「允许突破本学期学分要求」。
- 勾选「课程豁免先修课」后：课程与学年学期必填（红星）；课程标签单行展示，超出裁切不换行。
- 课程选择器表头增加当前页一键全选。
- 主列表去掉「来源」列；demo 名单扩至 **25** 行（含现有演示学号）。

## 增量（2026-09）：通知列与操作

- 白名单选人池可选学生不少于 **10** 人（扩候选人）。
- 去掉「演示：设为已逾期」；操作「发送邀请」统一为「发送通知」。
- **发送通知**：未发送或仍在有效期内可发；再发不限次数，每次递增次数并重置时效。
- **再次开放**：仅已逾期时单独展示，与发送通知分开；不再受 max 2 限制。
- 「邀请时效」拆为「发送通知次数」「生效剩余时间」。
- 「加入时间」→「添加白名单时间」；统一 `DD-Mon-YYYY`（如 `10-Sep-2025`）。

## 增量（2026-09）：Callout / 菜单 / demo 全状态 / 抽屉默认

- 去掉 Callout「加课申请不可突破…审批或缴费」一句。
- 隐藏侧栏「模块说明」菜单组（暂不展示）。
- 「选课过程」菜单顺序：加退课审批 → 缴费名单 → **学生选课监控** → 白名单。
- 「邀请门权限有效时长（小时）」→「权限有效时长设置（小时）」。
- 勾选「允许加退课/重修申请」后默认加/退/重修三子项全开。
- 初始 demo 覆盖：未发通知、有效期内可再发、已逾期（可见再次开放），并穿插多种权限组合。

## 增量（2026-09）：通知弹框 + 缴费列名 + 演示学生

- 「发送通知」「再次开放」复用监控 `MonitorRemindModal`：可编辑主题/正文后确认发送。
- 再次开放确认即 **开放 + 再次发送通知**（默认发信，无「只开门不发」）。
- 演示学号 `XMUM2309001`（Tan Wei Ming）保持**有效白名单**（窗外可申请），不再作逾期样本；逾期/再次开放用其他学生演示。
- 缴费名单：「最低学分」→「本学期学分要求」；「最高学分」→「毕业学分要求」。

## 增量（2026-10）：先修豁免语义 / 弹框列 / 新增必填

- 「课程豁免先修课」语义：所选为目标课（豁免其先修要求），非勾选先修课本身；选择框占位改为「请选择课程豁免先修课」。
- 先修选课弹框按教学班行展示（课程 + 课程分组，并含学分/任课教师/上课时间地点）；勾选仍以**课程**为单位（同课多分组同步勾选），确认仍写课号列表。
- 新增白名单：选择学生、备注均为必填（红星）；编辑不强制备注。
