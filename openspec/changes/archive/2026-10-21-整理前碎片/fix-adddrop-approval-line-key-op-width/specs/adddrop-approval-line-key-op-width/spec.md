## ADDED Requirements

### Requirement: 审批行决策按申请类型独立

单条审批弹窗中，同一课程代码与课程分组若同时存在退课与加课（或重修）行，各行 MUST 拥有独立行决策与评价意见，MUST NOT 共用同一 radio 组或同一决策 map 键。批量通过 MUST 可为上述各行同时设为通过。

#### Scenario: 同课同组退+加均可通过

- **WHEN** 申请含退 COMP201 分组03 与加 COMP201 分组03，且两行均勾选后点批量通过
- **THEN** 两行操作均为「通过」

### Requirement: 操作列完整展示评价入口

审批课程表操作列 MUST 加宽至可通过/不通过/驳回与「添加评价」（或「编辑评价」）同排完整可见，MUST NOT 因列宽不足导致评价按钮被明显裁切。

#### Scenario: 评价按钮可见

- **WHEN** 打开含多行的审批弹窗
- **THEN** 每行末尾评价按钮文案完整可见
