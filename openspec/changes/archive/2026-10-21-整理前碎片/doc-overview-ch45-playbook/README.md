# 使用说明

## 变更包

`openspec/changes/doc-overview-ch45-playbook/`

| 文件 | 用途 |
|------|------|
| `proposal.md` | 背景与范围 |
| `design.md` | 缺料闸门、结构优先级、去 AI 腔、样式、占用策略 |
| `specs/overview-design-ch45/spec.md` | 可验收规则 |
| `tasks.md` | 每次套用检查清单（含闸门） |
| `inputs-template.md` | 输入表（模板+章节+参数+结构确认） |
| `runs/` | 历史运行 inputs 归档 |

## 对话触发

- `@概要设计四五章编写`（目录名兼容；能力已是**按模板填指定章节**）
- 或说明：「按手册，用某模板写第×章，参数如下…」

Agent 须先 Read 本变更包的 `design.md` 与 `spec.md`，再生成。

## 最小输入

1. 一个文档模板  
2. 要写第几章（可多章）  
3. 对应参数点内容  

可选：对标产品资料（文风参考）。**若用户点名对标却未提供，须先提示等待拍板，不得直接成稿。**

结构以模板为准：概要类才默认「模块划分 / 功能列表 / 功能详细描述」；详细设计第四章主体为「用户接口设计 → 4.1 用户接口 → 4.1.n」，其后为全局变量/公用界面或接口/公用方法。见 `design.md` D2b 与 `runs/`。

## 已跑过的例子

- 基础支撑 × 权限平台三点 → 概要设计第四、五章  
- 数据中台 × 系统运维 → 概要设计第四、五章  
- 权限平台三点 → 详细设计第三、四章（目录对齐详细设计模板，非概要四级）

目录名 `doc-overview-ch45-playbook` 保留兼容；规则已不再绑定「只能写概要设计第四五章」。
