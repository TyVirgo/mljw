# 选课批次 · 特殊学生选人弹窗

## ADDED Requirements

### Requirement: 选择学生搜索区单行布局

选择学生弹窗的搜索条件「学号」「姓名」「学院」以及查询、重置操作必须排列在同一行，不得将「学院」单独放到换行后的二级搜索行。

#### Scenario: 打开弹窗即可看到三条件同排

- **当** 用户打开批次特殊学生「选择学生」弹窗
- **则** 学号、姓名、学院输入/下拉与查询、重置出现在同一搜索行
- **且** 不存在仅用于展开学院的「展开/收起」控件

#### Scenario: 按学院筛选仍可用

- **当** 用户在同排「学院」下拉选择某学院并点击查询
- **则** 列表仅展示该学院候选学生（行为与改版前展开筛选一致）

### Requirement: 选人弹窗与触发框字体样式统一

「请选择学生」触发框及选择学生弹窗内的标签、输入框、表头与表体字体样式必须与选课管理列表页既有搜索区/表格规范一致（字号、字重、颜色、控件高度），不得使用明显偏离的独立字号体系。

#### Scenario: 触发表单与弹窗观感一致

- **当** 用户在特殊学生新增表单看到「请选择学生」占位框并打开弹窗
- **则** 触发框与弹窗搜索输入、表格文字在字号与颜色上与列表页控件对齐，无明显「另一套字体」感
