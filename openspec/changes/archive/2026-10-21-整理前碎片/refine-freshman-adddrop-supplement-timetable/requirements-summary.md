# 需求摘要：加退课 / 补注册时效 / 课表与课程库

> 来源变更包：`openspec/changes/refine-freshman-adddrop-supplement-timetable`  
> 用途：对外需求说明书摘录；实现以该变更 `specs/` 与原型为准。

## 1. 新生加退课

| 规则 | 说明 |
|------|------|
| 默认 | 新生仅 GE/ME 在线选课；不可常规加课/退课/重修 |
| 例外 | 学分不足（如转学分）→ 教务/AC **手工**入补注册；可仅开「加课」 |
| 监控 | 学分&lt;12 可「建议加入」；确认后入名单；**不自动开门** |

## 2. 老生截止（与 intake 无关）

- 同批次共用申请窗截止
- 长学期：开课第 2 周周五 17:00；短学期：第 1 周周五 17:00
- **系统三轮选课时间 ≠ 加退课表单申请窗**（流程指引已区分）

## 3. 超期特批 = 补注册 + 24h×2

1. 入名单 →「发送邀请」（模拟邮件）
2. **自发送时刻**起 24 小时须填写
3. 逾期 →「再次开放」第 2 次再 +24h（最多 2 次）
4. 第 2 次仍逾期 → 人工处理

## 4. 学生课表多阶段

挂现有页（不新菜单），**按需展示**：

- 在线选课：工具栏「我的课表」抽屉
- 加退课：仅申请表单内预览
- 我的结果：工具栏「我的课表」抽屉（旁同步 Study Plan，与在线选课一致）

## 5. 课程库与一览

- 在线选课顶栏：ME/GE Library 文档名 demo
- 点 **课程代码** 开详情；「课程一览」按课号排序（仅可选范围）

## 6. 非目标

真邮件/真 PDF、新侧栏菜单、学分&lt;12 自动开门、重做 GE/ME 双受众名额（已另包）。

## 7. 页面映射

| 能力 | 页面 |

| 新生闸门 / 加退预览 | 学生加退课 |

| 课表 / 课库 / 点码 | 在线选课、我的结果 |
