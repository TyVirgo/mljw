## 背景与动机

马来本科教务第 7、8、9 次调研明确：选课（Course Registration）是当前人工负担最重、规则最复杂的环节之一。现状包括 Excel 导表筛查、M1/G1 与 Add/Drop/Retake 多平台割裂、复学/转学分学生无法在线补选、学分与 G1 类别合规靠 AC 人工核对等。

现有 `ly-cea-pjxt-jcsj-ui` 已完成教学门户、基础数据、学籍管理（含异动审批等列表+抽屉范式）。需在门户中**新增独立的选课管理应用**，复用既有 UI 壳层与审批交互模式，以可交互原型验证业务流程，再分期对接开课、排课、培养方案、Study Plan、财务等外部系统。

## 变更内容

### Phase 1（可演示闭环）

- 在教学门户增加「选课管理」应用入口（与学籍管理并列）
- 实现 **选课批次**、**可选课程**、**学生选课监控**、**加退课/重修审批** 四个页面
- 外部依赖数据以 demo + tooltip 占位
- 固化调研规则：三轮选课、新老生配额、学分上下限、Retake F/M 优先级、Add&Drop 关联审批、48h 账单窗口（可配置）

### Phase 2（运维闭环）

- **补注册名单**、**选课结果**、**学业预警**
- 监控/预警 → 补注册名单联动；导出 Excel

### Phase 3（治理与扩展）

- **候补名单**（人工审批，不做自动递补）、**白名单管理**、**选课报表**
- **演示环境默认入口**：刷新直达 `course-registration` / `cr-batch`
- **Demo 数据增厚**：各模块枚举类别全覆盖（批次类型/状态、监控标签、审批 Tab、补注册类型等）
### Phase 4（体验与核心加厚）

- **模块说明面板**：每页顶部展示调研来源、文档需求要点、本页功能映射
- **底色提示体系**：info / warning / rule 三级 callout
- **选课报表**：默认选中首张卡片，明细常驻，列头 i18n
- **批次轮次表单**：Pre/Main/Supp + Add/Drop 结构化配置
- **白名单新建**：支持创建草稿申请
- **选课队列页**：高并发提交时半透明灯箱队列提示（参考购票队列 UX，底层页面可见）

### Phase 5（学生端与体验收敛）

- **学生端 5 页**：在线选课、我的课表、加退课/重修、我的候补、我的选课结果
- **在线选课页**：可点击切换 Pre/Main/Supp/Add-Drop 四轮；轮次卡片 tooltip；G1 进度收拢至统计卡内；课程列表居中主区；demo 课程 15+ 门
- **Add/Drop 轮次**：点击第四轮卡片直接跳转「加退课/重修」菜单页，不在线选课页展示中间说明
- **选课队列**：半透明灯箱；默认等待 5–8 秒

### Phase 6（选课资格引擎）

- **`studentEligibility.js`**：统一判定批次 Program+Intake 范围、学籍有效状态、先修课、已修课程、课程受众（专业/批次/新老生）
- **白名单/补注册联动**：BOA 批准的先修例外、补注册 `bypassPrerequisite` 可豁免先修校验
- **学生在线选课页**：展示资格列与不可选原因；`addToCart` 拦截；支持按资格筛选

### Phase 7（模块流程说明页）

- 侧边栏置顶 **「流程说明」** 菜单（`cr-flow-guide`）
- **单页自上而下**：学期时间轴 A–K → 管理端/学生端双泳道主流程 → 两端联动 → 8 条顺序约束
- **节点可点击**跳转对应原型功能页；点击时间轴阶段高亮相关节点
- **非业务实现**：仅原型全局说明，明确标注非编排引擎

### Phase 8（批次抽屉体验对齐）

- **四步序号**：对齐学籍 `StudentProfileFormDrawer` 的 `step-badge` 样式
- **学年学期**：`2024/09` 格式下拉，与学籍/异动模块一致
- **轮次日期**：改用 `DatePickerEn`；草稿步骤 2–4 均可选填
- **保存校验**：仅步骤 1（名称、学年学期、类型）必填；发布仍校验 scope

### Phase 9（批次/课程类型 ME·GE·Mandatory）

- **类型枚举**：`M1→ME`（Major Elective）、`G1→GE`（General Elective），保留 `Mandatory`
- **集中常量** `registrationTypes.js`；旧值 `normalizeRegistrationType` 兼容
- **批次类型字段** tooltip 说明三类含义；下拉展示 `ME · 专业选修` 等
- **课程 type**、列表/筛选/详情同步；监控展示文案 G1→GE（内部 key 保留）

### Phase 17（学生端课程详情与列表优化）

- **`StudentCourseDetailDrawer`**：对齐学籍详情 section 排版；三段（基本信息 / 教学分组 / 修读说明）；footer「立即选课」；**不展示选课资格区块**
- **`CourseSectionCard`**：教学分组卡片复用；满员禁用、选中高亮
- **列表列收敛**：合并原「状态 + 容量」为「名额状态」；资格列短标签 + tooltip 完整原因；操作列仅保留按钮（详情 / 立即选课 / 候补 / 已在篮）
- **立即选课快捷路径**：单分组有余量直达加购；多分组打开详情选组后 footer 确认
- 管理端 `SelectableCourseDetailDrawer` **不变**

### Phase 19（批次与可选课程融合 + 课程库选择器）

- **侧边栏移除「可选课程」**；课程配置并入「选课批次」
- 批次操作列统一 **「管理课程」**：打开绑定该批次的课程抽屉
- 点击「课程数」同样打开管理课程抽屉（不再跳转独立页）
- **从课程库导入**：多选课程选择器；已导入课程置灰
- 访问旧 `cr-courses` 时重定向到 `cr-batch`
- 流程说明：原「可选课程」节点并入批次说明

### Phase 20（批次列表轮次拆列）

- 列表「选课轮次」拆为四列：**预选（Pre）/ 正选（Main）/ 补选（Supp）/ Add/Drop**
- 单元格值为各阶段时间段（`start–end`）；未配置显示 —
- 时间展示格式与表单 `DatePickerEn` 一致：`DD/MM/YYYY – DD/MM/YYYY`
- 导出字段与列表对齐，四列可独立勾选；不再提供合并的 `roundsSummary` 导出列

### Phase 21（学生端排课四字段）

- 教学分组展示 **任课教师 / 起止周 / 上课时间 / 上课地点**
- `classTime` 对齐排课文案（如 `(1-9周 星期一第1-4节)`）；`time` 保留供周课表解析
- 起止周、上课时间提供字段说明 ⓘ（区分开课周 vs 课时周）
- 落点：教学分组卡片/课程详情、选课篮、课表与选课结果；主课程列表不扩列
- 管理端可选课程详情教学分组表同步四列

### Phase 22（术语：班 → 分组 / Section → Group）

- 本系统无「班级」概念，开课单元统一称 **教学分组**（EN: **Group**）
- 中文：教学班→教学分组；班号→分组编号；相关提示/列表/Tab/流程说明一并替换
- 英文展示：Section→Group；Sections→Groups；sectionCode→Group No.
- 仅改 i18n 与说明文案；代码字段名 `section` / `sectionCode` 保持不变

### Phase 23（学生端加退课/重修申请体验）

- 去掉本页选课轮次条；工具栏仅批次名 +「发起申请」（去掉 Add/Drop/学分/待审批描述）
- 申请列表「申请内容」改为「申请课程」，单元格仅展示课号
- 页内与弹框说明用底色 callout；弹框取消/提交补齐标准按钮底色
- 「发起申请」弹框填类型与课程；Drop 用已选课程；类型本地化

### Phase 24（候补 / 选课结果去统计卡）

- 「我的候补」「我的选课结果」去掉顶部 `stats-row` 统计卡片
- 列表与批次说明作为主内容

### Phase 25（我的候补只读）

- 申请候补操作仅保留在「在线选课」（满员入口）
- 「我的候补」只展示当前学生候补记录，不可在本页申请/操作
- 去掉本页选课轮次条；说明与模块简介改为只读查询导向

### Phase 26（在线选课 demo 情况覆盖）

- 重构 `selectableCourses` demo：各类情况至少各 1 条；砍重复缺先修行
- **已满且符合先修** 的候补候选置顶，并对齐 `waitlistCourses`
- 列表排序：候补候选 → 可选有余量 → 已修 / 缺先修 / 专业·Intake 限制 / 满员不可选

### Phase 27（在线选课去统计卡）

- 「在线选课」去掉顶部四格 `stats-row`（轮次 / 学分环 / 选课篮数 / 可选门数）
- 学分仍见右侧选课篮；轮次仍见时间轴；列表直接成为主内容

### Phase 28（我的课表去统计卡）

- 「我的课表」去掉顶部四格 `stats-row`（轮次 / 学分环 / 门数 / 学期）
- 主内容为说明 + 周课表 + 已选课程列表；轮次条暂保留

### Phase 29（弹框提示与课表轮次条精简）

- 加退课「发起申请」弹框内去掉规则 callout 提示（页内说明保留）
- 「我的课表」去掉四轮 `RoundTimelineBar`，以及批次名 + 课表说明行

### Phase 30（详情 / 选课 / 候补职责拆分）

- **详情**：只读查看，教学分组卡片无选中态、无 footer「立即选课」
- **立即选课**：始终打开独立选组弹框（含仅 1 个有余量分组）；加购进选课篮后提交
- **申请候补**：不选教学分组；课程级进选课篮（展示预计候补位等），与正式选课一并提交后入候补队列（任意分组待分配）

## 能力范围

### 新增能力

- `course-registration`：选课批次配置、可选课程、选课监控、加退课/重修审批、补注册、候补、选课结果、学业预警、白名单、报表、**学生端在线选课五页**

### 不修改的能力

- 学籍异动、基础数据、开课排课模块（仅只读引用或 demo）

## 影响范围

- `App.vue`：默认应用与 Phase 3 路由
- `AcademicPortalView.vue`：应用卡片
- `src/config/courseRegistrationMenu.js`：10 页全部可访问
- `src/views/courseRegistration/*`、`src/components/courseRegistration/*`
- `src/data/courseRegistration/*`（含 waitlist、whitelist、report 数据层）
- `src/i18n/locales/zh.js`、`en.js`

## 非目标

- 不实现真实排课、开课、培养方案维护
- 不实现 Study Plan 真实同步、财务真实支付
- Waiting List 自动递补

## 成功标准

- 刷新后默认进入选课批次页
- 10 个子菜单均可交互演示（无 UnderConstruction 占位）
- 各列表页搜索区与操作按钮位置与学籍管理一致（搜索在上、工具栏在下）
- 各模块 demo 覆盖文档定义的全部类别/状态枚举
- AC 可完成：批次 → 课程 → 监控 → 审批 → 补注册 → 预警 → 候补 → 白名单 → 报表 全路径
- 学生可完成：在线选课（含轮次切换 demo、队列）→ 课表 → 加退课申请 → 候补 → 结果 演示路径
- 学生端 5 页均展示批次轮次时间轴与页面说明
- 在线选课 Add/Drop 轮次卡片点击后直接跳转加退课页
- 学生在线选课对不可选课程展示明确原因（先修/范围/已修/学籍），且加入选课篮时强制拦截
- 侧边栏「流程说明」页可一页浏览全流程，节点可点击跳转各功能页
