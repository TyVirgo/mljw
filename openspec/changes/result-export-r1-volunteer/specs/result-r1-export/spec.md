## ADDED Requirements

### Requirement: 第一轮主表勾选与导出入口

课程维度·第一轮主表 MUST 在序号列前提供多选列（含表头全选当前页）。志愿工具条 MUST 提供「导出」按钮。勾选单位 MUST 为课程×教学分组行。

#### Scenario: 打开第一轮课程维度

- **WHEN** 管理员进入选课结果课程维度且轮次为第一轮
- **THEN** 可见行勾选列与工具条「导出」
- **AND** 发布/发布日志按钮仍可用

### Requirement: 主表导出明细与汇总

主表导出 MUST 提供导出类型「明细」「汇总」，默认「明细」。明细 MUST 为学生×课×分组行，且 MUST 包含是否选上。汇总 MUST 为课程×分组一行并对齐主表关键容量字段。导出范围 MUST 支持当前页、全部筛选结果、已选行（无勾选选「已选行」时 MUST 提示）。

#### Scenario: 默认导出明细

- **WHEN** 管理员打开导出弹窗
- **THEN** 导出类型默认为明细
- **AND** 可选字段为明细字段集

#### Scenario: 按已选课程导出明细

- **WHEN** 管理员勾选若干分组行、选择明细与「已选行」并确认
- **THEN** Excel 仅包含这些分组下的志愿学生明细行

#### Scenario: 导出汇总

- **WHEN** 管理员选择汇总并确认
- **THEN** Excel 每行对应一个课程×分组汇总

### Requirement: 志愿名单抽屉导出

志愿名单抽屉 MUST 提供「导出」。导出 MUST 为明细（本课本分组）。范围 MUST 支持当前页、全部过滤结果、已选学生。批次已定稿只读时 MUST 仍可勾选并导出；MUST NOT 因此重新启用添加或批量移除。

#### Scenario: 只读抽屉导出

- **WHEN** 批次已最终确认且管理员打开志愿名单
- **THEN** 可见勾选列与「导出」
- **AND** 不可见添加学生与批量移除（或禁用）

#### Scenario: 勾选学生导出

- **WHEN** 管理员勾选若干学生并选择「已选行」导出
- **THEN** Excel 仅包含所选学生

### Requirement: 已有结果页导出尊重范围

学生维度与课程维度第二/三轮的导出 MUST 按 ExportModal 的 exportScope 切片数据（当前页 / 全部 / 已选行），MUST NOT 始终导出全部筛选行。

#### Scenario: 学生维度已选行导出

- **WHEN** 管理员在学生维度勾选若干明细行并选择「已选行」导出
- **THEN** 文件仅含勾选行
