## 修改需求

### 需求：未开发的异动与学习计划页面
系统应对尚未开发的菜单项展示应用内「建设中」页面。

#### 场景：未开发的异动子菜单
- **当** 用户选择学籍异动统计
- **则** 系统展示「建设中」页面，并提供返回学生基本信息的操作

#### 场景：异动类别已开发
- **当** 用户在侧边栏选择异动类别
- **则** 系统展示异动类别配置列表页，而非「建设中」页面

#### 场景：学籍异动查询已开发
- **当** 用户在侧边栏选择学籍异动查询
- **则** 系统展示异动查询列表页，而非「建设中」页面

#### 场景：未开发的个人学习计划子菜单
- **当** 用户选择个人培养方案
- **则** 系统展示「建设中」页面，并提供返回学生基本信息的操作

## 新增需求

### 需求：学籍异动查询注册为已开发页面
系统应将 `sr-movement-query` 注册为已开发的学生档案页面。

#### 场景：侧边栏导航
- **当** 用户在学籍异动下选择学籍异动查询
- **则** 侧边栏高亮学籍异动查询
- **且** 主内容区渲染 `MovementQueryView`

#### 场景：面包屑
- **当** 用户位于学籍异动查询页面
- **则** 面包屑展示学籍异动分组标签与查询页面标签
