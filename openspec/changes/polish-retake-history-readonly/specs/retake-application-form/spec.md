## ADDED Requirements

### Requirement: 重修节曾修课程成绩只读历史展示

重修申请分节 MUST 将原「曾修成绩」与「曾修学年学期」合并为单一字段「曾修课程成绩」。该字段 MUST 在选定本学期重修课程后，按该生该课往期成绩单全部记录展示，每行格式为「学年学期 + 空格 + 中文等级」（示例：`2025/04 良好`），多行顺序 MUST 按学年学期从新到旧。缺考成绩 MUST 展示为「缺考」。该字段 MUST 为只读、置灰、不可编辑，且 MUST NOT 作为可选手动必填项。

#### Scenario: 选课带回多行历史成绩

- **WHEN** 学生选定一门本学期重修课程且该课有多条往期成绩
- **THEN** 「曾修课程成绩」只读框按行展示全部记录
- **AND** 成绩为中文等级而非字母
- **AND** 字段不可编辑且无必填星号

#### Scenario: 缺考展示

- **WHEN** 某条往期成绩为缺考（字母 M）
- **THEN** 对应行展示「缺考」

### Requirement: 重修节去掉课程分组表单字段

重修申请分节 MUST NOT 展示「课程分组」下拉。课程分组 MUST 在选课器选择本学期重修课程时一并选定；表单 MUST 仍保留选课器写入的分组标识以便提交。详情页 MUST NOT 再单独展示「课程分组」行作为必填业务字段。

#### Scenario: 表单无分组下拉

- **WHEN** 学生打开重修申请并已选课
- **THEN** 不见课程分组下拉
- **AND** 起止周、上课时间地点、任课教师等已由选课带回

### Requirement: 选课带回字段只读置灰

以下由选课/成绩单带回的字段 MUST 置灰、只读、不可改，且 MUST NOT 要求学生手填：曾修课程成绩、起止周、上课时间地点、任课教师、学分、超出学分、费用相关只读展示。「重修类型」MUST 仍为可选手动且提交前必填。「本学期重修课程」MUST 仍通过选课操作选择。

#### Scenario: 时间地点与教师不可手填

- **WHEN** 学生已选定重修课程及分组
- **THEN** 上课时间地点与任课教师为只读置灰
- **AND** 无手填提示作为提交前提

#### Scenario: 重修类型仍必填可改

- **WHEN** 学生填写重修申请
- **THEN** 重修类型为下拉且带必填标识
- **AND** 可根据默认值修改后提交

### Requirement: 重修类型默认不及格重修

主类型为重修时，重修类型下拉 MUST 默认选中「不及格重修」（`failed`），且「不及格重修」MUST 为选项列表第一项。下拉 MUST NOT 提供「请选择」空选项。编辑已有申请时 MUST 保留原 `retakeType`。重修类型 hint 文案 MUST NOT 因本要求变更。

#### Scenario: 新建重修默认不及格

- **WHEN** 学生将申请类型选为重修（或打开新建重修表单）
- **THEN** 重修类型显示「不及格重修」
- **AND** 下拉选项中「不及格重修」在「提升成绩重修」之前
- **AND** 无「请选择」空项

#### Scenario: 编辑保留原类型

- **WHEN** 学生打开已保存且重修类型为提升成绩的申请
- **THEN** 重修类型仍为「提升成绩重修」

### Requirement: 字母成绩映射中文等级

系统 MUST 将往期字母成绩映射为中文后展示：A/A-→优秀；B+/B/B-→良好；C+/C/C-→中等；D→及格；F→不及格；M→缺考。

#### Scenario: B- 显示良好

- **WHEN** 往期成绩字母为 B-
- **THEN** 曾修课程成绩对应行显示「良好」

### Requirement: 重修课必有历史成绩约束（demo）

Demo 数据 MUST 保证可选重修课程均能匹配到至少一条往期成绩记录；MUST 保证所选分组带回的上课时间地点与任课教师非空。

#### Scenario: 选重修课必有历史行

- **WHEN** 学生从选课器选择一门可重修课
- **THEN** 「曾修课程成绩」至少有一行有效展示（含缺考文案）

### Requirement: 退课仅允许选修

退课及重修关联/加退关联中的退课选课 MUST 仅列出选修课（GE/ME）。系统 MUST NOT 将必修（CORE 或课表 required 来源）列入可退课程。我的课表仍可展示必修，但 MUST NOT 因此使其可退。

#### Scenario: 退课弹窗无必修

- **WHEN** 学生打开退课或重修关联的退课选课
- **THEN** 列表不含 MATH101/PHYS101 等必修
- **AND** 所列选修与课表中的确认选修一致

### Requirement: 重修关联按退费抵免冲抵应收学分

重修关联申请中，「退费抵免」选择「是」表示用退课学分抵扣重修费用。此时应收（超出）学分 MUST 为 `max(0, 重修学分 − 退课学分)`，预估费用 MUST 为 `应收学分 × 科类单价`。退费抵免为「否」或纯重修时，应收学分 MUST 为重修课程学分，费用按整课计算。表单「超出学分」、费用明细与选课弹窗计费 MUST 使用同一结果；MUST NOT 出现应收为 0 而金额仍按整课收取的情况。

#### Scenario: 抵免且重修学分更大

- **WHEN** 学生已选退课 2 学分、退费抵免为是，并选择 3 学分重修课
- **THEN** 超出学分为 1
- **AND** 预估费用为 1 × 该课科类单价

#### Scenario: 抵免后无超出

- **WHEN** 退课与重修学分相等且退费抵免为是
- **THEN** 超出学分为 0
- **AND** 预估费用为 0
- **AND** 选择重修课时不弹出超额缴费提示

#### Scenario: 不抵免按整课

- **WHEN** 退费抵免为否并选择重修课
- **THEN** 超出学分等于重修课程学分
- **AND** 费用按整课学分 × 单价

### Requirement: 选重修课时按抵扣结果条件提示

在重修关联流程中选择重修课程时，系统 MUST 使用当前已选退课学分与退费抵免选项计算应收学分；仅当应收学分大于 0 时 MUST 在确认前提示可能缴费；应收为 0 时 MUST NOT 强制弹出超额缴费提示。

#### Scenario: 有超出才提示

- **WHEN** 抵免后仍有应收学分并确认选择重修课
- **THEN** 出现超额/缴费相关提示后方可回填
