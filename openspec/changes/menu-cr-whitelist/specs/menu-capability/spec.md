## 新增需求

### 需求：白名单

系统 MUST 按现行白名单页展示权限与学习模式相关信息。

#### 场景：查看白名单

- **当** 用户打开学生白名单
- **则** 列表与权限控件符合当前实现

### 需求：已选学生字段同步（增量 bm）

新增白名单选择学生后，已选区 MUST 展示与选人弹框一致的字段：学号、姓名、性别、学院、专业、入学批次。

#### 场景：多选两名学生

- **当** 用户在选人弹框确认两名学生
- **则** 表单已选区每人可见上述字段（可主行+副行布局），不仅显示姓名

### 需求：延期开门与窗口内权限分列（增量 bm/bn）

「允许加退课/重修申请」MUST 表述为窗口外延期，时长前缀 MUST 为「延期申请时长为」。新增时该父项 MUST 默认不勾选。布局（bn）：左列为申请窗口时段 + 窗口内例外权限；右列为延期块。窗口内权限 MUST NOT 再配置与延期相同的小时数。

#### 场景：配置仅窗口内豁免

- **当** 用户不勾选延期，仅勾选课程豁免先修课等窗口内权限
- **则** 可保存；左列可见申请窗口时段只读展示

### 需求：生效剩余时间绑定延期（增量 bm/bn）

主表「生效剩余时间」MUST 仅在该行具备延期权限（`supplement`）时展示未发送/倒计时/已逾期；否则 MUST 显示 `NA`。

#### 场景：有延期且已逾期

- **当** 行勾选延期且邀请门已过期
- **则** 生效列显示已逾期，并可「再次开放」与（有效期内的）发送通知规则

#### 场景：无延期行（NA）

- **当** 白名单行未勾选延期
- **则** 生效剩余时间为 `NA`；仍可「发送通知」（告知，不起算延期）；MUST NOT「再次开放」
