# 变更：refine-freshman-adddrop-supplement-timetable

## Why

在 GE/ME 新老生双时间与名额模型（`align-ge-me-senior-freshman-model`）落地后，老师补充了加退课策略、超期特批时效、学生课表可见性与课程库一览等口径。现原型：加退课页对新生未区分；申请窗/退课截止周与「长学期 week2 周五 5pm / 短学期 week1 周五 5pm」未对齐；补注册名单无邀请邮件与 24 小时时效；学生课表入口弱；课程代码详情入口被弱化。本变更在**不新增侧栏菜单**前提下，基于现有加退课、补注册、批次、在线选课、我的结果、流程指引整合上述逻辑，供后续用中文变更包生成项目需求文档，并指导原型实现。

## What Changes

### 新生加退课策略

- 新生默认**仅**参与 GE/ME 在线选课，**不开放**常规重修 / 加课 / 退课。
- 例外：入学转学分等导致本学期学分低于最低学分（12）时，经教务/AC **手工**加入补注册白名单后，可申请加课（名单可仅开 `canAdd`）。
- 监控学分偏低可「建议加入补注册」，**不自动开门**。

### 老生加退课截止（与 intake 无关）

- 同一批次内不同 intake 共用同一申请窗截止。
- 口径：长学期 = 开课第 2 周周五 17:00；短学期 = 开课第 1 周周五 17:00。
- 批次申请窗与 `dropDeadlineWeek`（或等价）demo/默认对齐；系统三轮选课时间与加退课表单窗在指引中区分说明。

### 超期特批 = 补注册白名单 + 时效

- 超过常规截止后（长学期约第 3 周、短学期约第 2 周语境），特批走现有补注册名单，不新开菜单。
- 入名单后可「发送邀请」：模拟邮件通知；**自邮件发送时刻起算 24 小时**须完成填写。
- 逾期未填：管理员可「再次开放」第 2 次机会，再触发通知并再给 24 小时（最多 2 次，可配置）。

### 学生课表多阶段可见

学生须能在以下节点查看课表（复用现有课表数据结构，挂现有页，不新菜单）：

1. GE/ME 选课前（预览）
2. 第一轮预选时（志愿预览）
3. 第一轮结果公开后
4. 加 / 减 / 重修申请时（变更后预览）
5. 最终选课结果

**课表图层视觉（增量修订）**

- Demo 固定 **1～2 门必修**（字段同选修确认课，仅标记为必修；不接真实培养方案来源）。
- 格子按三色区分：**必修 / 已确认选修 / 本轮预览**；轮次用角标 `R1/R2/R3`（**不做**每轮一色）。
- 格内展示课号·组号等简要信息；悬停可见课名/教室/轮次等。
- R1 公示前：必修 + 已确认 + 志愿/篮预览（虚线预览色）；公示后：必修 + 已确认 + **中签**实线，落选不进表。

### 课程库与一览

- 选课相关入口展示课程库文档名/链接 demo（如 ME Open Elective Library、GE Course Library，含学年学期与版本日期）。
- 主表 **课程代码可点** 打开详情；提供按课号排序的一览（仅学生可选范围内；不可选不展示）。
- 在线选课顶栏课程一览右侧展示本学期 **公共选修（GE）/ 专业选修（ME）** 已选学分与可选上限（进度条，含篮内）；demo 帽抬高以便可先选若干课。
- 若选课后将超过该类型学期上限：行内选课按钮置灰，左侧感叹号 tip 说明原因（与提交闸门一致）。

### 监控进度与受众英文

- 选课监控详情进度由「GE 文科/商科」改为本学期 **GE / ME** 修读进度（已选/上限）。
- 英文展示：老生 → **Existing students**，新生 → **New students**（代码 key 仍可为 senior/freshman）。

### 课表与排课展示收口（增量）

- 学生周课表：行距收紧；左轴改为**时间段**；一日 **8:00–22:00**；课块 **5 行**（周在第 5 行）。
- 地点：教学楼与教室号之间用 `#`（如 `D5-5#101`）；在线选课「上课地点」列同步。
- 上课时间列：去掉「第 x–y 节」；中文 `(星期 09:00–11:00)`；英文对齐 `(Tuesday 9.00am-11.00am)`。

### UI / 文档约束

- 不新增侧栏菜单；样式与选课模块一致；中英 i18n。
- 本变更包中文撰写，便于导出为需求文档。

## Non-goals

- 不对接真实邮件服务 / 真实 PDF 课程库后端（原型 mock + 外链名即可）。
- 不新建「课表中心」「白名单中心」「课程库中心」独立菜单。
- 不自动将所有学分 &lt; 12 新生直接开放加退课。
- 不重做 GE/ME 双受众轮次与名额初分（已由 `align-ge-me-senior-freshman-model` 覆盖）。
- 不做生产级审批流改造（特批仍走加退课申请 + 补注册开门）。

## 已确认决策（探索阶段拍板）

| 议题 | 结论 |
|------|------|
| 新生例外入名单 | 以教务/AC **手工**加补注册为主；监控可建议，不自动开门 |
| 24 小时起算点 | **邮件发送成功时刻**起算；再次开放再发通知并再 +24h |
| 与前序变更关系 | **独立变更包**；依赖前序身份/受众能力，不合并进 align-ge-me 正文 |
| GE/ME 进度分子 | **含篮内未提交**，与超限校验一致 |
| Demo 学分帽 | 默认抬高为 GE≤12、ME≤16（可按学生覆盖） |
| 课表图层 | **三色**（必修 / 已确认 / 预览）+ 轮次角标；demo 1～2 门必修；不做每轮一色 |
| 受众英文 | Existing students / New students |
