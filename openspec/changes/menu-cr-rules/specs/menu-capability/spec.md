## 新增需求

### 需求：选课规则

系统 MUST 提供与当前代码一致的「选课规则」能力。

#### 场景：查看规则

- **当** 用户打开本菜单
- **则** 界面与数据符合现行实现

### 需求：校级规则目录与白名单同构（增量 af）

选课规则目录 MUST NOT 再展示「不及格可重修选课」（原 CR202）。

「允许突破本学期学分要求，不超过（分）」（CR204）MUST 为校级全局可超学期学分上限额度，规则值 MUST 为 1–3 的整数（启用时）；语义 MUST 与白名单「允许突破本学期学分要求，可超 N 分」相同，范围分别为全局 vs 指定学生。运行时有效可超额度 MUST 取校级与白名单之较大值。

「缴费时长不超过（小时）」（CR107）MUST 以小时为单位配置校级全局缴费宽限；MUST NOT 再以「天」作为规则值单位。非重修应付账单的缴费截止 MUST 按该小时数计算。白名单中的申请/延期时长仍为按学生配置，MUST NOT 与本条混为同一字段。

#### 场景：校级可超学分对全体生效

- **当** 校级 CR204 启用且规则值为 3，学生无白名单突破学分权限
- **则** 该生加退/选课学分闸门允许超出学期上限至多 3 分

#### 场景：白名单可超高于校级

- **当** 校级可超为 1、白名单为该生配置可超 3
- **则** 有效可超为 3

#### 场景：缴费按小时截止

- **当** 校级 CR107 启用且值为 48，非重修申请审批通过产生应付
- **则** 缴费截止为通过时刻起 48 小时（非 48 天）

#### 场景：目录无不及格可重修

- **当** 打开选课规则页
- **则** 列表 MUST NOT 出现「不及格可重修选课」行
