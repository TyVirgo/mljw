## 背景

整合历史增量，仅保留当前应然行为。校级「选课规则」与白名单、批次 localRules 存在同话题多层配置，本增量先对齐学分突破与缴费时长的全局语义。

## 目标 / 非目标

**目标：**

- 规则维护
- 校级 CR204 / CR107 与白名单同构（分 / 小时），范围分别为全局 vs 单生
- 目录去掉未使用的 CR202

**非目标：**

- 不新增未实现引擎
- 本增量不清理批次「不及格可重修」勾选

## 决策

1. 以当前代码为真源；增量 af 起以本 design 为准覆盖目录语义  
2. 全中文  
3. 历史包见 SOURCES.md  
4. **CR204（增量 af）：** `type=count`，启用时规则值钳制 1–3（与 `CREDIT_BYPASS_EXTRA_*` 一致）；关闭则有效可超=0。有效额度 = `max(校级可超, 白名单可超)`；任一侧>0 即视为可 bypass  
5. **CR107（增量 af）：** 存「小时」；`getPaymentGraceHours()` 替代天数读取；非重修账单用 `addHoursToDateTime`。旧存档若值≤14（疑似天）读库时 ×24 迁移。重修仍默认 72 小时硬编码  
6. **CR202：** 从 `REGISTRATION_RULE_IDS` / 默认表移除；localStorage 残留 id 忽略  
7. 存储键升 `registration-rules-v5`，缺省与迁移由 load 合并完成
