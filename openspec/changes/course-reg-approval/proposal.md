# 选课管理-加退课审批

> 本变更包由同菜单下多个历史 OpenSpec 变更合并而成，供后续整理需求文档使用。实现状态以原型代码为准；本包作为需求沉淀，不重复驱动增量开发。

## 背景与动机

管理端加退课/重修审批承接学生申请，按待办/已提交/历史处理；详情需突出审批流程，列表字段与学生端对齐便于对照。

## 能力范围（按逻辑分组）

### 1. 退课截止分支

- 开课后 Drop 按教学周分自助 / 特殊审批通道；学生页演示教学周切换（数据模型保留 `dropChannel`）。

### 2. 列表与详情对齐学生端（增量）

- 列表去掉类型旁「退课通道」标签与合并「申请内容」列。
- 同步三列：添加课程名称 / 退课课程名称 / 重修课程名称（编码 + 名称）。
- 详情抽屉**继续突出审批流**（时间线 + 审批弹窗）；申请内容区按类型展示完整课程与表单字段。
- **详情排版（增量）**：与学生端同步——分区灰条、标签上置、附件卡片（预览/导出）；时间线与审批入口不变。
