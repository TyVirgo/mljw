# 选课管理-选课批次

> 本变更包由同菜单下多个历史 OpenSpec 变更合并而成，供后续整理需求文档使用。实现状态以原型代码为准；本包作为需求沉淀，不重复驱动增量开发。

## 背景与动机

选课批次是管理端配置「谁能在何时选哪些课」的核心菜单。历史变更覆盖批次表单与轮次分工、学生范围、特殊学生、管理课程、名单抽屉及大量列表/抽屉体验打磨。本包按配置链路重组，便于写需求文档。

## 能力范围（按逻辑分组）

### 1. 批次主数据与表单

- 批次类型以选修场景为主（ME / GE）；命名对齐业务（如 Major Elective Selection）。
- 新建/编辑：基本信息、是否可选、局部规则描述、Add/Drop；**不在此配置三轮选课**（轮次在「管理轮次」）。
- 支持存草稿；账单付款窗口迁到选课规则（按天）；加退课由申请窗口控制；超额优先收敛为高年级。
- 列表可横滑，左右冻结关键列；参与范围列展示条件条数并可点开明细。

### 2. 参与范围（按轮配置）

- 范围维度：学院 / **专业批次**（基础数据 `programmeIntake`，如 `202509IBU`）；支持「全部」。
- **学院与专业批次不做联动过滤**；默认均为「全部」、非必填、可多选修改。
- **每个选课轮次至多一条**学生范围（不可同轮多条）。
- 每条范围旁展示 **学生数量：N**，点击进入批次学生清单「可选学生」并定位该轮次。
- （历史）学院/专业/入学批次拆分维度已合并为专业批次。

### 3. 学生名单：特殊学生 + 可选学生

- 操作入口进入学生清单抽屉：外层 Tab **特殊学生名单**（整批、不按轮）｜**可选学生名单**（按三轮）。
- 可选名单支持学号/姓名分搜、专业列；样式对齐管理课程抽屉。

### 4. 管理课程与开放轮次

- 从培养方案导入（文案不再称「课程库」）；去掉空态重复导入按钮。
- 主表展示课程类别、先修、分组数（可点开分组明细）；容量语义为已选/容量。
- **可选设置**：课程从哪一轮起对学生可见；学生端 demo 体现轮次差异。

### 5. 轮次独立性（与学生端联动）

- 预选 / 正选 / 补选各自独立选课篮与搜索条件；切换 tab 不共享清单。
- 教学分组可演示多时间/教师；正选说明避免误解容量共享规则。

### 6. 列表与抽屉体验统一

- 参与范围明细、可选名单、管理课程等抽屉表格对齐批次列表视觉（灰表头、横线等）。
- 原型后缀文案统一为「正式页面去掉」。

## 增量（2026-07 学生范围·专业批次·每轮一条）

- 专业+批次合并为专业批次；默认全部、非必填、多选；无学院联动。
- 管理轮次：每轮仅允许一条范围；旁注学生数量可跳转名单对应轮次。

## 增量（2026-07 学生范围按钮 + 专业范围扩展）

- 管理轮次「学生范围」弹窗：取消/确定按钮样式对齐其它弹窗（补 scoped `.btn`）。
- 管理课程「专业范围设置」增加学生类别（中国/国际/本地）、校选类别（文科/商科/理科）；均必选至少一项；仅配置存档，本轮不接入学生端校验。
