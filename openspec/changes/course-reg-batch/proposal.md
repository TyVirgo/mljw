# 选课管理-选课批次

> 本变更包由同菜单下多个历史 OpenSpec 变更合并而成，供后续整理需求文档使用。实现状态以原型代码为准；本包作为需求沉淀，不重复驱动增量开发。

## 背景与动机

选课批次是管理端配置「谁能在何时选哪些课」的核心菜单。历史变更覆盖批次表单与轮次分工、学生范围、特殊学生、管理课程、名单抽屉及大量列表/抽屉体验打磨。本包按配置链路重组，便于写需求文档。

## 能力范围（按逻辑分组）

### 1. 批次主数据与表单

- 批次类型以选修场景为主（ME / GE）；命名对齐业务（如 Major Elective Selection）。
- 新建/编辑：基本信息、是否可选、局部规则描述、Add/Drop；**不在此配置三轮选课**（轮次在「管理轮次」）。
- 支持存草稿；账单付款窗口迁到选课规则（按天）；加退课由申请窗口控制；超额优先收敛为高年级。
- 列表可横滑，左右冻结关键列；参与范围列展示条件条数并可点开明细。

### 2. 参与范围（按轮配置）

- 范围维度：学院 / **专业批次**（基础数据 `programmeIntake`，如 `202509IBU`）；支持「全部」。
- **学院与专业批次不做联动过滤**；默认均为「全部」、非必填、可多选修改。
- **每个选课轮次至多一条**学生范围（不可同轮多条）。
- 每条范围旁展示 **学生数量：N**，点击进入批次学生清单「可选学生」并定位该轮次。
- （历史）学院/专业/入学批次拆分维度已合并为专业批次。

### 3. 学生名单：特殊学生 + 可选学生

- 操作入口进入学生清单抽屉：外层 Tab **特殊学生名单**（整批、不按轮）｜**可选学生名单**（按三轮）。
- 可选名单支持学号/姓名分搜、专业列；样式对齐管理课程抽屉。

### 4. 管理课程与开放轮次

- 课程来自培养方案；**隐藏**工具条「添加课程」入口（导入弹窗可保留不删），旁侧「可选设置 / 容量设置 / 名额分配 / 专业范围设置」靠左自适应。
- 主表按**课程分组**展平：一门课有几个分组就几行；去掉「课程分组数」聚合列与点开分组明细入口。
- 分组明细外提：课程分组、任课教师、起止周；**上课时间地点**合并多行展示（对齐学生在线选课）。
- **勾选具体到课程分组**；新老生已选/容量为**分组自有**；分页「共 N 条」按分组行数；工具条描述为「本批次已有 X 门课程，包含 Y 课程分组」。
- 主表**去掉「源最大容量」列**；「课程分组」列置于**课程名称后**并左冻结。
- **可选设置 / 专业范围 / 容量百分比**：对勾选分组所属课程去重后按课操作；**名额分配**作用于勾选的分组。

### 5. 轮次独立性（与学生端联动）

- 预选 / 正选 / 补选各自独立选课篮与搜索条件；切换 tab 不共享清单。
- 教学分组可演示多时间/教师；正选说明避免误解容量共享规则。

### 6. 列表与抽屉体验统一

- 参与范围明细、可选名单、管理课程等抽屉表格对齐批次列表视觉（灰表头、横线等）。
- 原型后缀文案统一为「正式页面去掉」。

## 增量（2026-07 学生范围·专业批次·每轮一条）

- 专业+批次合并为专业批次；默认全部、非必填、多选；无学院联动。
- 管理轮次：每轮仅允许一条范围；旁注学生数量可跳转名单对应轮次。

## 增量（2026-08 ME 入学年名额占比）

- 管理轮次 · 老生第一轮 · ME 容量细分：去掉表上「选择入学学年 + 添加入学学年」。
- 「+ 新增」与「当前合计」同一行置于表上：左新增、右合计；专业说明文案移到表下。
- 入学年改为行内下拉（新年份在前）；默认展示锚点年未到的下一年至往前共 6 年（当前 2026 → 2027–2022）；已占用年不可再选。
- 「份额」改为「名额占比（%）」；单行 0–100；全部行合计必须为 100%；超过 100% 提示且不写入；保存时合计不是 100% 则拦住。
- 默认三年由相对权重 5:3:2 改为 50% / 30% / 20%。

## 增量（2026-08 管理轮次时间与系数必填）

- 管理轮次：第一轮开始时间、结束时间、结果发布时间、GE 衰减系数 r（及 ME 名额占比）为必填，标签加 `*`。
- 第二/三轮解锁后，开始/结束时间同样必填。
- 保存时空值必须拦截。
- 参与范围仍非必填，不加 `*`。
- 第二轮锁定说明改为：到达公布时间自动锁定后再配置，不再提「最终确认」。

## 增量（2026-08 去掉退课截止周填写）
