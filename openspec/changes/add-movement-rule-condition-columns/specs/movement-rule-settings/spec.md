## 新增需求

### 需求：异动规则设置页增加条件展示字段

系统应在异动规则设置列表中展示每条规则适用的学期类型、学生类别、异动类别及申请时间范围，帮助业务人员快速识别规则用途。

#### 场景：新增列展示
- **当** 用户查看异动规则设置列表
- **则** 表格在「规则名称」与「规则值」之间显示 4 列：学期类型、学生类别、异动类别、申请时间（开学后【周】）

#### 场景：字段只读
- **当** 用户查看新增列
- **则** 列中文本仅用于展示，不响应编辑操作

#### 场景：不适用字段展示占位符
- **当** 某条规则对某个条件字段不适用时
- **则** 该列显示 `-`

#### 场景：申请时间范围展示
- **当** 规则的 `applicationWeek` 存在时
- **则** 显示为 `start ~ end` 格式
- **否则** 显示 `-`

#### 场景：向后兼容
- **当** 已有 `movement-rules-v2` 存储数据缺少 `condition` 字段时
- **则** 系统使用内置默认值补齐，不破坏现有数据
