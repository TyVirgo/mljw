# 异动规则设置页增加条件展示字段

## 背景
现有异动规则设置页仅展示规则名称、可编辑规则值与启用开关。业务人员无法直观看到每条规则适用的学期类型、学生类别、异动类别及申请时间范围，维护时容易混淆。本期在规则名称之后、规则值之前增加 4 个只读条件字段，用于明确规则适用范围。

## 变更内容
- 在 `MovementRuleSettingsView.vue` 表格中新增 4 列，位于「规则名称」与「规则值」之间：
  1. 学期类型（长学期 / 短学期 / -）
  2. 学生类别（中国 / 本地 / 国际 / -）
  3. 异动类别（转专业 / 休学 / 复学 / 退学 / -）
  4. 申请时间（开学后【周】：数字 1~数字 2 / -）
- 4 个字段仅展示、不可编辑；当前规则不适用该字段时显示 `-`。
- 在 `movementRules.js` 中扩展规则对象，内置每个规则对应的条件数据。
- 更新中、英文 i18n 列头与枚举文案。

## 影响
- `src/data/movementRules.js`
- `src/views/studentRecords/MovementRuleSettingsView.vue`
- `src/i18n/locales/zh.js`、`src/i18n/locales/en.js`

## 非目标
- 不修改规则的持久化存储 key（沿用 `movement-rules-v2`）。
- 不将新增字段开放给用户编辑。
- 不接入申请/审批校验逻辑。
