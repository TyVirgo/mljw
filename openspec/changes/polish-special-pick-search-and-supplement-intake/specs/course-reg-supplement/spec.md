# 补注册名单 · Intake 展示

## ADDED Requirements

### Requirement: Intake 以年/月格式展示

补注册名单列表中的 Intake（入学批次）必须按与其它学年学期一致的 **年/月** 格式展示，即 `YYYY/MM`（例如 `2024/09`），不得直接展示未格式化的紧凑码（如 `2409`）。

#### Scenario: 列表展示年/月

- **当** 用户打开补注册名单页且某行原始 intake 为 `2409` 或 `202409` 或 `2024/09`
- **则** 该行 Intake 列显示为 `2024/09`

#### Scenario: 导出一致（若含 Intake 列）

- **当** 用户导出补注册名单且导出字段包含 Intake
- **则** 导出单元格同样为 `YYYY/MM` 格式

### Requirement: 入学批次表头文案

补注册名单列表表头 必须使用与其它选课名单一致的「入学批次」文案（i18n），必须NOT 写死英文 `Intake`。

#### Scenario: 中文界面表头

- **当** 界面语言为中文
- **则** 该列表头显示「入学批次」
