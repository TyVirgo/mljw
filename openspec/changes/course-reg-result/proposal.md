# 选课管理-管理端选课结果

> 本变更包由同菜单下多个历史 OpenSpec 变更合并而成，供后续整理需求文档使用。实现状态以原型代码为准；本包作为需求沉淀，不重复驱动增量开发。

## 背景与动机

管理端选课结果供教务核对各轮选课成效、维护第一轮志愿名单、按学生/课程/轮次查看明细，并支持代选与批量清理。历史变更重构 Tab 结构、明细粒度与数据来源口径。本包按结果查看与运维链路重组，便于写需求文档。

## 能力范围（按逻辑分组）

### 1. Tab 结构与第一轮志愿

- Tab 顺序：**第一轮志愿** | **按轮次** | **按学生**；进入页面默认「第一轮志愿」。
- 第一轮志愿按教学分组维护：各分组容量独立且之和为课总容量；主表一行一分组，补齐选择器与 demo 数据。
- 去掉页顶 Study Plan 同步说明 callout 及「一键同步 Study Plan」按钮（按学生 / 按轮次均去掉）。

### 2. 按学生/按课程明细展示

- 「按学生」主表改为学生×课程明细行（一门一行，参考缴费抽屉课程列粒度，不含欠费等缴费字段）。
- 「按轮次」：先选轮次再看该轮全部课程选课情况，与「按课程」信息去重。

### 3. 数据来源与操作人

- 选课结果仅展示已确认成功课（学生自选 + 管理端代选），与 `studentConfirmedCourses` / 我的选课成功行同步；补齐「课程来源」区分轮次自选与管理端代选。
- 学生端选课结果表增加「操作人」列：管理端代选显示管理员，自选显示 —，tooltip 说明规则。

### 4. 管理端批量操作

- 「按学生」工具条提供 `[导出] [删除]` 等批量操作；勾选 + 确认弹框，按钮样式对齐学籍模块。
- 「按轮次」以查看结果为主：**三轮均去掉行内「添加学生」操作列**；不再从轮次表进入代选（只看容量/已选情况）。按学生 Tab 仍可保留结果维护能力。

### 5. 移除候补名单

- 去掉管理端菜单与页面入口 `cr-waitlist`（在线选课已无候补操作，容量满后等退课再进队列）。

## 增量（2026-07 批次顶栏与志愿名单）

- 页顶增加批次选择（对齐学生端），同步控制第一轮志愿 / 轮次维度 / 学生维度三 Tab 数据。
- 志愿名单抽屉：容量内/外行底色区分分界；文案统一为「志愿数量/课程容量」。

## 增量（2026-07 全批次结果 demo + 下拉宽度）

- 全部选课批次在三个 Tab（第一轮志愿 / 轮次维度 / 学生维度）均有可演示数据；缺课批次补轻量课表与名单种子。
- 页顶批次下拉宽度按批次名称自适应（对齐学生在线选课 `measureSelectWidth`）。
- 因各批均有数据，不再做「有数据靠前」排序。

## 增量（2026-07 志愿名单随机排序）

- 志愿名单抽屉「添加学生」旁增加「随机排序」；确认后对**全部志愿**洗牌，顺序保留，无 Undo。
- 未点「保存」的调整（含随机/添加/移出）不写入已保存名单；关闭抽屉丢弃未保存草稿。
- 保存只落当前名单（成员+顺序）；容量内视为本课选上；手动添加追加到容量内末位；已满须先移出再添加。

## 增量（2026-07 志愿名单批量移出与姓名展示）

- 超额 demo 姓名不再附加括号序号，展示干净姓名（学号仍可用后缀保证唯一）。
- 志愿名单表序号前增加多选列；工具行增加「批量移除」，确认后从草稿移出，须保存才落库。

## 增量（2026-07 按批次最终确认）

- 最终确认按**当前页顶批次**各自一次；已定稿不可再次确认。
- 有/无最终确认须有状态文案标识；定稿后本批志愿只读，并**禁用「志愿名单」入口**。

## 增量（2026-07 学生维度新增代选）

- 学生维度工具行「导出」旁增加「新增」：一次选一名学生，再为其选择未满员教学分组加课。
- 写入结果的课程来源为「管理员添加」；满员课程/分组不可选。

## 增量（2026-08 代选弹窗批次只读与按钮样式）

- 「新增学生选课」先展示页顶当前选课批次（只读不可改），再选该批次下未满员「课×分组」。
- 目标课程班与表单控件样式对齐列表搜索区；页脚取消/确定补齐 `btn` 样式（与同类弹窗一致）。
