## 新增需求

### 需求：异动规则设置页

系统应提供异动规则设置菜单页，展示内置规则列表；不允许新增、删除或搜索。

#### 场景：菜单导航
- **当** 用户在学籍异动侧边栏选择「异动规则设置」
- **则** 系统展示内置规则表格

#### 场景：规则名称只读
- **当** 用户查看规则列表
- **则** 规则名称显示内置文案且不可编辑

#### 场景：修改规则值
- **当** 用户点击某行「修改」并保存新规则值
- **则** 系统更新该规则数值并持久化到 mock 存储

#### 场景：切换是否启用
- **当** 用户切换某行是否启用开关
- **则** 系统立即更新启用状态并持久化

#### 场景：无新增与搜索
- **当** 用户查看异动规则设置页
- **则** 不显示新增按钮与搜索区域
