## Why

加退重修申请虽已按 PDF 分节展示，但仍按「课程」粗选并自动塞第一教学组，缺少组级时间/地点/教师、课表冲突拦截、加课资格过滤、成绩单驱动重修，以及按科类学分单价的费用试算。列表也无法同步关键业务字段。需在现有分节表单之上补齐选组、校验、计费与主表展示，使原型可演示真实申请规则。

## What Changes

- 选课改为两步：**先选课程 → 再选教学分组**；分组确认后分字段回填上课时间、地点、任课教师（不再合并为一格；不再自动选第一组）。
- 与当前课表**时间冲突的教学组默认不可选**，并提示冲突对象与时段；需先退课/换课后才可选。
- **加课候选**收紧为曾 Drop 或休学落下的、**本学期开课**课程；后续学期课程不出现在可选列表，Notes 说明规则。
- **重修**：可从 demo 往期成绩单选择曾修记录并回填成绩/学期；区分挂科重修与刷分重修（不影响单价公式）。
- **费用试算**：`应收学分 × 科类单价`（文科 500 / 理科 550 / 商科 600）；重修一般按整课学分计费；GE/ME 补选按超额学分计费；声明前提示费用摘要。
- 学生/审批**主列表**同步展示分组、时间、地点、教师、费用等字段；重要列冻结 + 横向滚动。
- 详情抽屉与提交 payload 持久化上述字段。
- **增量（列表 Tab 化）**：学生端对齐学籍异动申请，按 **Add / Drop / Retake / AddDrop** 四个 Tab 分开展示；各 Tab 仅保留该类型所需主表列；表头单行不换行；「发起申请」锁定为当前 Tab 类型（表单内不再切换类型）。管理端审批仍用既有状态 Tab，本增量不拆类型 Tab。
- **增量（排课 demo）**：主表增加 **起止周**；demo 申请补齐任课教师 / 起止周 / 上课时间（中文节次文案）/ 上课地点，对齐排课模块图示样本，列表不出现空值或「—」占位。
- **增量（Notes / 状态 / 审批同步）**：填写说明按当前申请类型删减；学生与审批列表状态改为颜色胶囊；demo 保证五状态各至少 2 条且四类型均有差异行；管理端保留状态 Tab，列同时展示状态与申请类型，类型筛驱动与学生同源的动态列。
- **增量（课程分组与选课收口）**：列表/表单「课程分组」展示分组名称；选课弹窗只确认课程，分组改表单下拉；弹窗搜索左标签右输入、去掉资格来源列、加课 tip。
- **增量（表单说明与学分）**：加课「加课类型」改为只读学分（选课带出）；Notes 去掉分节填写指引与费用长文并顺序编号；去掉零费用灰字；Section V 增加分类型其他申请说明。
- **增量（列表操作列与表单字号）**：学生主表操作列加宽并保持「详情 / 取消」横排不折行；分节标题字号大于正文一档，四类型共用；Notes 与提示字号一并收口。
- **增量（课表入口与弹窗字号）**：申请弹窗内嵌课表迁至主页「发起申请」旁「我的课表」抽屉（对齐在线选课）；申请弹窗表单字号整体小一号。
- **增量 §11**：学生主表「上课时间/地点」合并为「上课时间地点」多行（meetings 1–3）并补 demo；填写说明标题按 Tab/类型区分；声明勾选与文案同行垂直对齐；**重修 Tab 已恢复**（Add/Drop/Retake/AddDrop）。
- **增量 §12（选课弹窗按分组 + SECTION 连续编号）**：四类申请「选择课程」弹窗按课程分组展平一行一组，展示课程分组 / 任课教师 / 起止周 / 上课时间地点（对齐在线选课）；确认同时回填课+组。表单与详情 SECTION 标题按**当前可见分节**连续编号（I–III/IV 不跳跃）。
- **增量 §13（加课选课学分与筛选）**：加课/联合加课选课弹窗搜索下展示本学期学分（已选/要求）胶囊；超额选课确认前提示超出学分与可能收费；搜索同行增加学分、课程类型；申请表单学年学期只读默认当前学期。
- **增量 §14（选课弹窗排版与超额双提示）**：搜索区标签与输入同一行；去掉学分条下静态费用句；页脚确认左侧条件提示超额；确认仍弹二次确认；demo 仅保留一组冲突、并留一门可选可触发超额。
- **增量 §15（校选类别列/筛与间距）**：选课弹窗主表在课程类型前增加校选类别列；搜索区在课程类型前增加校选类别筛选；压缩学分胶囊灰底上下内边距与上课时间地点多行行距。
- **增量 §16（超额确认层级与表格紧凑）**：超额确认框 z-index 高于选课弹窗；主表除上课时间地点外列不换行并支持横滑，单元格行距收紧。
- **增量 §17（加课节预估费用字段）**：加课/重修分节在学分旁增加只读「预估费用」及单价 tip（1学分：文/理/商）；保留声明前费用汇总块。
- **增量 §18（超出学分与加课费用块上移）**：加课节教师与学分同行；增加超出学分；费用预估块移到补充说明上方（仅加课/联合加退）；列表与详情同步超出学分列；重修费用块位置不变。

### Non-goals

- 不改造真实计费/财务接口或审批流引擎规则（原型 mock 试算与展示即可）。
- 不复刻「选加课后因冲突强制填退课节」的默认路径（冲突组直接禁用）。
- 不接真实成绩系统；往期成绩单为 demo 数据。
- 不撤销已落地的 I–V 分节与声明结构（本变更在其上增量）。
- 不把管理端审批列表拆成四类型 Tab（与「待我审批 / 已提交 / 历史」状态 Tab 正交，避免双层 Tab）。
