# 选课管理-选课监控

> 本变更包由同菜单下多个历史 OpenSpec 变更合并而成，供后续整理需求文档使用。实现状态以原型代码为准；本包作为需求沉淀，不重复驱动增量开发。

## 背景与动机

学生选课监控供 AC 按专业/入学批次查看学分与 GE 合规、识别异常并处置（提醒、加入补注册）。本包按监控主链路重组，便于写需求文档。

## 能力范围（按逻辑分组）

### 1. 预警并入监控

- 学业预警与监控同源，单表展示问题类型、严重度；支持仅异常 / 严重度 / 类型筛选；去掉独立预警菜单。

### 2. 本轮选课情况展示收敛

- 本轮选课情况仅展示：排队中、成功、失败；不再展示取消选课行。

### 3. Intake 与详情体验（增量）

- 列表 Intake、详情副标题统一为 `YYYY/MM`（`formatIntakeBatch`），与其它选课页一致。
- 问题清单：补齐/对齐 issue 文案键（含超上限 `creditAboveMax`），禁止露出 i18n key。
- 详情 footer 去掉「模拟在线选课提交」；保留加入补注册名单与关闭。

### 4. 白名单文案与学分详情（增量 2026-09）

- 监控操作列 / 详情 footer：统一「加入白名单」，去掉「建议加入白名单」。
- 详情「本学期学分要求」「毕业学分要求」均按 GE / ME：**总分 + 类别**（GE 含文商理 AI，ME 含文商理），排版一致；对齐在线选课入口维度。

### 5. 详情课表与历史（增量 2026-09）

- 详情标题「周课表」改为「本学期课表」。
- 详情去掉「操作历史」区块（demo 种子可保留字段，UI 不展示）。

### 6. 监控预警分层与提醒弹框（增量 2026-09）

- 本学期 GE/ME/校选类别未满 → 中严重提醒（允许后续学期补）。
- 毕业选修：进度不足一半且临近毕业（剩余长学期 ≤2），或缺口大于「剩余学期 × 学期选修上限」→ 高严重。
- 主表增列「本学期 GE」「本学期 ME」；统计卡「GE 风险」改为「选修缺口」。（「毕业缺口」列后续已去掉，见 §8）
- 「发送提醒」先弹可编辑主题/正文（默认带缺口要素），确认后再发送（演示）。

### 7. 监控列表与详情 UI 收敛（增量 2026-09）

- 提醒弹框「取消 / 确认发送」按钮样式与详情 footer 一致（`btn-outline` / `btn-primary`）。
- 主表表头不换行（含序号、专业、严重程度等）。
- 主表去掉「建议操作」列（处置仍走操作列与详情）。
- 详情去掉「问题清单」区块。
- 「本学期 GE/ME」拆成两列：「本学期 GE」「本学期 ME」（如 `13/18`）。

### 8. 监控主表列再收敛（增量 2026-09）

- 主表去掉「状态」「预警类型」「毕业缺口」列（筛选与严重程度列仍保留；详情与提醒承载明细）。
- 原「学分」列改为「毕业学分（已选/要求）」，数据口径为毕业选修已修/要求（`earned/required`），不再用学期 `credits/creditMax`。
- 「本学期 GE」「本学期 ME」表头加「（已选/要求）」字样，单元格仍为 `已选/要求`。

### 9. 统计卡 / Intake / 白名单确认（增量 2026-09）

- 统计卡与主表口径对齐：去掉「低于最低」「超上限」；「平均学分」改为「平均毕业学分」（按毕业选修已修均值）；保留应参与 / 已参与 / 选修缺口 / 高·中严重。
- 筛选与表头「Intake」统一为「入学批次」。
- 「加入白名单」（列表操作列与详情 footer）必须先确认弹框，确认后才写入名单。
